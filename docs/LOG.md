## 状态流转

需求的**状态**改在 [REQ.md](REQ.md)（那是唯一分配源），本文件只跟一条理由或触发条件：

- 提了想做 → REQ.md 登记一行、状态「待拍板」、占号；理由与背景写进本文件「判断依据」
- 拍板做 → REQ.md 该行状态改「在办」，**沿用原号**（另取新号会让 `git log --grep` 指向一个从未开工的号）；进展去 `docs/PLAN.md` / `docs/large/`
- 已决定推迟 → REQ.md 状态**仍是**「待拍板」，本文件写「触发条件：…」。全局 v8.2 取消了「暂缓」这个状态值，两种待拍板靠本表有没有触发条件区分
- 明确不做 → REQ.md 状态改「已作废」+ `~~` 划掉保留（号不复用），本文件写否决理由，**两侧行都永久保留**（号与理由是同一机制的两面，不要因为删一边就把另一边也回收）
