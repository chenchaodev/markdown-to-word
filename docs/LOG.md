## 状态流转

- 提了想做 → 进「待拍板」
- 拍板做 → **保留该行**并在其后标「进行中」，**不要删**（下个会话靠它接上下文），实际进展去 `docs/PLAN.md`
- 这次不做但以后要 → 改「暂缓」，**必须写触发条件**
- 明确不做 → 改「不做」+ 原因，**行永久保留**（墓碑，防 agent 下个月重新提同一个方案）
