## 五、需求侧趋势（2025–2026 的新变量）

1. **分发渠道从「下载 exe」迁移到「Skill / MCP」** —— 2026 年新进入 md→docx 的项目**绝大多数形态是 Agent Skill 或 MCP server**，不是桌面 GUI。安装动作变成 `npx skills add <repo>`。已有成品：`mcp-markdown-to-docx` · `aigroup-mdtoword-mcp` · `mcp-ms-office-documents` · `docx-mcp` · PyPI `mcp-docgen`。
2. **AI 直接产出 docx —— 上游被 WPS 吃掉** —— [WPS 智能文档](https://365.wps.cn/content/f9c63f7488664bd594daf653ecb63c7b.html)（2026-10-09）：「深度融合 GB/T 9704 公文格式标准，通过 AI 级自动排版引擎实现输入即成型…内置国标模板…支持离线编辑」；旗舰版 599 元/人/年，**支持私有化部署**。WPS 365 累计年度付费用户 4,825 万。
3. **中文规范成为事实锚点** —— GB/T 9704-2012（版心 156×225mm、每页 22 行×28 字、28 磅固定行距、三号仿宋_GB2312、二号方正小标宋、页码「—1—」单右双左）被 2026 年的项目直接实现；GB/T 7714-2015 参考文献 CSL 成为中文默认。已知约束：方正小标宋为**商业授权字体不能随包分发**，只能写字体名由 Word 回退。
4. **信创 / 私有化部署成为硬需求** —— [统信·畅写文档中台](https://faq.uniontech.com/solution/b0c1/368d)：国资 79 号文要求 2027 年基础软硬件 100% 替代；「MS Office 与国产 Office 的渲染引擎差异导致跨平台打开时排版错乱、字体丢失、公式变形」；[WPS 信创转换平台](https://365.wps.cn/content/9ff0b64d379e4723955d5a8a87bae96c.html) 支持十万级批量与私有化。
5. **反向链路（docx→md）爆发** —— `microsoft/markitdown` **191,601★** · `firecrawl/anydoc` **23,036★** ⇒ 「文档 ↔ Markdown」整体被 AI 生态接管，但**只吃读侧**。
6. **专业排版链路继续吃学术与成书场景** —— Typst **56,761★** · Quarto **6,115★**（均月更）⇒ 需要交叉引用、参考文献、图表清单、PDF 书签的用户已迁走，**Markdown→docx 路线的天花板是「交付稿」而非「出版物」**。

## 七、反证：这个品类在萎缩或被取代的迹象

1. **桌面 Markdown 编辑器本身在收缩再集中** —— MarkText 停摆 4 年半；Zettlr 为 Pandoc 版本 bump 疲于奔命 ⇒ 用户向 Obsidian（插件生态）或 Typora（买断）集中。
2. **Obsidian 已自带 PDF 导出并持续增强** —— 官方帮助页已提供纸张 / 页边距 / 降比例 / 暗色导出，路线图含 Mobile PDF export 与 PDF annotation；中文社区官方答复方向是"先试试 Ob 自带的导出 pdf" ⇒ 插件只剩书签 / 页码 / 批量合并的增量。
3. **上游 WPS 用「AI 直接生成 + GB/T 9704」正面吃掉定位** —— 见趋势第 2 条，它就是本定位的商业化形态（云协同 + 生成器，非本地转换器）。
4. **专业排版链路在长文档与学术场景持续抽血** —— Typst / Quarto / LaTeX。
5. **品类供给爆炸但无一胜出** ⇒ "纯转换器"形态的价值捕获能力差（见第三节观测量）。
6. **通用 Agent Skill 正在替代专用转换器** —— 同题实测专用工具快（148.3s vs 381.8s / 312.8s），但通用 Skill 已可用且**零安装成本** ⇒ 专用工具的护城河只剩"确定性 + 可重复 + 不依赖模型"。
7. **「本地离线」本身正在被复制为卖点，而非差异化** —— docformat-gui 网页版强调浏览器本地断网可用；WPS 智能文档主打离线编辑 ⇒ **离线正从差异点降级为基线要求**。
8. **桌面 GUI 形态的信任成本上升** —— Word-Formatter-Pro FAQ：「下载的 .exe 被杀毒软件报毒…非签名可执行文件可能触发部分杀毒软件误报」；docformat-gui 许可从宽松改为 **PolyForm Noncommercial 1.0.0（商用需授权）** ⇒ 商业化在发生，但发生在**许可收紧**而非提价。

## 九、证据缺口（引用前先看这节）

- `markdownskill/md-to-docx` 的 48.6K 总量 / 2.6K 周下载**来自第三方聚合站自报**，非 GitHub 官方 API，属**二手指标**。

- 未核实：VS Code Marketplace / Open VSX 的实际安装量；Gitee 镜像仓的 star 与下载数；Winget 各包的实际安装量（`api.winget.run` 只返回标识符）。
