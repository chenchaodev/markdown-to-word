## 一、部件清单（自家产物实际有的）

以 `output/artifacts/basic-render.docx` 为例（`docx@9.7.1`）：

```
word/document.xml          word/styles.xml        word/numbering.xml
word/settings.xml          word/fontTable.xml     word/footnotes.xml
word/endnotes.xml          word/comments.xml      word/footer1.xml（页眉开启时另有 header1.xml）
word/media/<sha1>.png      ← 图片
word/_rels/document.xml.rels  word/_rels/footnotes.xml.rels  word/_rels/comments.xml.rels
[Content_Types].xml        docProps/core.xml      docProps/app.xml      docProps/custom.xml
```

**没有 `word/theme/theme1.xml`** —— 自家稿不含主题部件（字体走 `docDefaults` 的显式 `w:rFonts`，不靠主题引用）。⇒ 解析层仍要读 theme（外部模板有），但**自家稿走的是「theme 缺失」这条路径**，映射层不能把 theme 当必需项。

图片文件名是 **sha1 十六进制 + 扩展名**（如 `b2bbe763c7e1828c750d53f78550709a6fea19be.png`），不是 `image1.png` ⇒ 回读器不能按序号猜文件名，须走 rels。

## 二、styles.xml 的实际形态

```xml
<w:docDefaults>
  <w:rPrDefault><w:rPr>
    <w:rFonts w:ascii="Calibri" w:eastAsia="微软雅黑" w:hAnsi="Calibri"/>
    <w:sz w:val="24"/><w:szCs w:val="24"/>          <!-- 24 half-points = 12pt -->
  </w:rPr></w:rPrDefault>
  <w:pPrDefault/>                                    <!-- 空 -->
</w:docDefaults>
<w:style w:type="paragraph" w:styleId="Heading1">
  <w:name w:val="Heading 1"/><w:basedOn w:val="Normal"/><w:next w:val="Normal"/><w:qFormat/>
  <w:rPr><w:color w:val="2E74B5"/><w:sz w:val="32"/><w:szCs w:val="32"/></w:rPr>
</w:style>
```

三条影响实现的事实：

**① `Normal` 样式在自家产物里根本不存在** —— `styles.xml` 里搜不到 `w:styleId="Normal"`，但 `Heading1` 却 `basedOn="Normal"`（指向一个不存在的样式）。⇒ **现有浅导入 `template-import.ts` 的 `extractTypography` 对自家稿取不到正文字号**（它取 `Normal` 样式块的 rPr，而该块不存在）。深导入（步 #02）**必须从 `docDefaults/rPrDefault/rPr` 取正文默认值**，并把「样式块不存在」当正常路径而非异常。

**② 标题字号有两处来源** —— `Heading1` 样式里的 `w:sz`（32 = 16pt，来自 docx 库默认样式）与**段落级 run 的 `w:sz`**（本仓按档位算出的标题字号写进 run）同时存在。⇒ 回读时**段落级 run 优先于样式级**。

**③ `basedOn` 链存在且会指向不存在的样式** —— `Heading1 → Normal`（Normal 缺失）。继承求解须容忍「父样式缺失」（按「取到即用、取不到即跳过」处理），**不能**因此判解析失败。环检测仍要留（防御外部模板的畸形数据）。

另：`styles.xml` **无 `w:themeFontLang`**；`settings.xml`（1395 字节）**无 `defaultTabStop`**、无 `themeFontLang`。

## 三、document.xml 的实际形态

| 语义 | 实际 XML |
|---|---|
| 正文段 | `<w:p><w:pPr><w:spacing w:line="360" w:lineRule="auto"/><w:ind w:firstLineChars="200"/><w:jc w:val="both"/></w:pPr>…` |
| 标题段 | `<w:pPr><w:spacing w:after="480" w:before="240"/><w:jc w:val="center"/></w:pPr>` + run 的 `<w:sz w:val="36"/>` |
| 行内样式 | run 级 `<w:rPr><w:b/><w:bCs/></w:rPr>` / `<w:i/><w:iCs/>` / `<w:rFonts w:ascii="Consolas" w:cs="Consolas" w:eastAsia="Consolas" w:hAnsi="Consolas"/>` |
| 列表 | `<w:numPr><w:ilvl w:val="0"/><w:numId w:val="2"/></w:numPr>` |
| 图片 | `<w:drawing><wp:inline …><wp:extent cx="9525" cy="9525"/>…<a:blip r:embed="rId8" cstate="none"/>` |
| 书签 | `<w:bookmarkStart w:name="G1-验证文档-中文标题" w:id="1"/>` |
| 交叉引用 | `<w:hyperlink w:history="1" w:anchor="G1-验证文档-中文标题">`（**内部锚点**，非外部 URL） |
| 目录域 | `<w:instrText xml:space="preserve">TOC \h \o &quot;1-3&quot; \u \z</w:instrText>` + `fldChar`（**无 `w:fldSimple`**） |
| 公式 | `<m:oMath><m:sSup><m:sSupPr/><m:e><m:r><m:t>x</m:t></m:r></m:e><m:sup>…</m:sup></m:sSup></m:oMath>` |
| 表格 | `<w:tbl><w:tblPr><w:tblW w:type="pct" w:w="100%"/><w:tblBorders>…` |
| 分页符 | `<w:br w:type="page"/>` |
| 批注 | `<w:commentRangeStart …/>`（仅注释类产物有） |
| 修订 | **无 `w:ins` / `w:del`** —— 自家稿不写修订标记 |

三条影响实现的事实：

**④ 题注编号不是 `SEQ` 域，是「纯文本 + 书签」** —— `captions.ts` 用自增文本（`图 1.`）+ `wrapBookmark` 包 `w:bookmarkStart/End`；产物里搜不到 `SEQ`。⇒ 回读自家稿时**题注是普通段落文本**（形如「图 1. 说明」），不必解析域就能还原；域解析只对外部模板（真 Word 用 `SEQ`）需要。

**⑤ 交叉引用是 `w:hyperlink` + `w:anchor`（内部锚点）** —— 回读时还原成 md 的锚点链接（`[文字](#书签名)`）即可，不涉及 `REF` 域。

**⑥ 域只有 `w:instrText` + `w:fldChar` 形态** —— 自家稿**不用** `w:fldSimple`。解析层两种都要支持（外部模板两种都有），但自家稿只走 `instrText` 这条。

## 四、numbering.xml 的实际形态

```xml
<w:abstractNum w:abstractNumId="1" w15:restartNumberingAfterBreak="0">
  <w:multiLevelType w:val="hybridMultilevel"/>
  <w:lvl w:ilvl="0" w15:tentative="1">
    <w:start w:val="1"/><w:numFmt w:val="bullet"/><w:lvlText w:val="●"/><w:lvlJc w:val="left"/>
    <w:pPr><w:ind w:left="720" w:hanging="360"/></w:pPr>
  </w:lvl>
  <w:lvl w:ilvl="1" …>…<w:lvlText w:val="○"/>…<w:ind w:left="1440" w:hanging="360"/></w:lvl>
  <w:lvl w:ilvl="2" …>…<w:lvlText w:val="■"/>…<w:ind w:left="2160" w:hanging="360"/></w:lvl>
</w:abstractNum>
<w:num w:numId="1"><w:abstractNumId w:val="1"/><w:lvlOverride w:ilvl="0"><w:startOverride w:val="1"/></w:lvlOverride></w:num>
```

- 本仓的列表是 **bullet 档用 `numFmt="bullet"` + 字面量符号（●○■）**；有序档用 `numFmt="decimal"`。⇒ 回读还原有序/无序时**看 `numFmt`**，不要看 `lvlText` 的字面量。
- 层级缩进是 `w:ind w:left`（720 / 1440 / 2160 twips，逐级 +720），**不是** `firstLineChars`。
- `w:num` → `w:abstractNum` 有 `w:lvlOverride`/`w:startOverride`（起编号重启）。

## 五、回读器要认的最小形态集（自家稿）

**必须处理**：`w:p`（含 `w:pPr` 的 `w:pStyle`/`w:numPr`/`w:jc`/`w:ind`/`w:spacing`）、`w:r`（含 `w:rPr` 的 `w:b`/`w:i`/`w:rFonts`/`w:sz`）、`w:t`、`w:tab`、`w:br`、`w:hyperlink`（`w:anchor` 与 `r:id` 两种）、`w:drawing`→`a:blip@r:embed` + `wp:extent`、`w:bookmarkStart/End`、`w:tbl`/`w:tr`/`w:tc`、`w:fldChar`+`w:instrText`（目录域）、`m:oMath`（公式）、`word/_rels/document.xml.rels`（`r:id` → 目标）、`word/media/*`（字节）、`word/numbering.xml`（`numId`→`abstractNum`→`numFmt`/`lvlText`/`ind`）、`word/styles.xml`（`docDefaults` + `basedOn` 链 + 段落级 run 优先）。

**明确不处理（自家稿不会出现，处理了也没有回报）**：`w:ins`/`w:del`（修订）、`w:fldSimple`（域的另一形态，外部模板才有）、`w:themeFontLang`、主题色引用（自家稿无 theme 部件）、`docProps/custom.xml` 的元数据回流（本轮不承诺）。

**本仓产物特征清单（回读器可依赖）**：正文字号在 `docDefaults`（无 `Normal` 样式）· 标题字号在段落级 run · 首行缩进是 `w:firstLineChars="200"` · 对齐是 `w:jc="both"` · 行距是 `w:spacing w:line w:lineRule="auto"` · 列表是 `numId`+`ilvl`+bullet 字面量 · 图片 sha1 文件名 + `a:blip@r:embed` · 题注是纯文本 + 书签 · 交叉引用是 `w:hyperlink@w:anchor` · 公式是 OMML（`m:oMath` + `m:sSup` 等结构）· 表格宽度用 `w:tblW type="pct"`。
