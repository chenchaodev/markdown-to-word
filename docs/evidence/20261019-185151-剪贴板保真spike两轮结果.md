# 剪贴板保真 spike · 两轮结果与形态裁决(REQ-254)

> 日期:2026-10-19。方法:一份全内联 `style` 的 HTML,浏览器打开后 `Ctrl+A` / `Ctrl+C`,分别粘贴进 Microsoft Word 与 WPS 文字,由用户目视回报。**未跑门禁链**。
> 外部依据一条(`librarian`,只读):Word/WPS 的 HTML 粘贴支持面与 CF_HTML 规则。

## 一、第一轮:直接沿用 pdf 的形态 —— 三条被判死

| 形态 | Word | WPS |
|---|---|---|
| 标题层级 / 中文字体 / 粗斜体下划线删除线 / 超链接 / 列表 | 正常 | 正常 |
| 代码块(`<pre>` + `background-color` + `border-left` + `padding`) | **底色与边框全丢**,只剩等宽字 | 底色与左侧竖线出现,但**每一行文字都带蓝框** |
| 引用块(`<blockquote>` + `border-left` + 底色) | **格式全丢** | 有格式,但**每行文字都带蓝框** |
| 表格(`border-collapse:collapse` + `width:100%`) | **超出版心,显示不全** | **超出版心,显示不全** |

### 判死原因(外部依据)

- Word 的粘贴路径不是浏览器排版:它把 HTML 转成 Word 段落/表格模型,块级文本容器(`p`/`div`/`pre`/`blockquote`)的盒模型不可靠。官方矩阵把 `padding`/`width`/`border-left` 长写列为 `p`/`div` 不支持(仅 `COREEXTENDED`),而粘贴转换器连 `pre`/`blockquote` 的盒属性也一并丢弃。
- WPS 认块级背景与 `border-left`,但会按「文字边框」逐行绘制块级边框 —— 这就是「每行蓝框」的来源。
- Word **不支持 `table-layout` / `max-width`**;Web 表格默认 AutoFit,`width:100%` 在粘贴路径上不可靠。
- 依据:Microsoft《Word 2007 HTML and CSS Rendering Capabilities》· Office HTML and XML Reference(Tables / Borders and Shading) · 实测。

## 二、第二轮:表格承载 + 固定 pt 宽 —— 两端全部符合预期

用户回报:**Word 与 WPS 均满足预期**。验证的形态:

### 代码块(单格表格,底色/边框只挂 `td`)

```html
<table border="0" cellspacing="0" cellpadding="0"
       style="border-collapse:collapse;table-layout:fixed;width:414pt;mso-table-layout-alt:fixed;mso-table-lspace:0pt;mso-table-rspace:0pt;margin:0 0 8pt 0;">
  <tr>
    <td style="background-color:#f5f5f5;border:1pt solid #d0d0d0;border-left:4pt solid #0070cc;padding:8pt;mso-padding-alt:8pt;mso-border-left-alt:solid #0070cc 4pt;font-family:'Consolas',monospace;font-size:9.5pt;line-height:1.5;color:#222;white-space:pre-wrap;">line1<br>line2</td>
  </tr>
</table>
```

### 引用块(单格表格,左边框 + 浅底)

```html
<table border="0" cellspacing="0" cellpadding="0"
       style="border-collapse:collapse;table-layout:fixed;width:414pt;mso-table-layout-alt:fixed;mso-table-lspace:0pt;mso-table-rspace:0pt;margin:0 0 8pt 0;">
  <tr>
    <td style="border-left:3pt solid #999999;background-color:#fafafa;padding:6pt 10pt;mso-padding-alt:6pt 10pt;mso-border-left-alt:solid #999999 3pt;font-family:'SimSun',serif;font-size:11pt;line-height:1.7;color:#555;">…</td>
  </tr>
</table>
```

### 数据表格(固定 pt 宽 + `table-layout:fixed`)

- 变体 A:`width:414pt;table-layout:fixed` + `th` 百分比列宽 —— **未溢出**
- 变体 B:`width:414pt` + 逐列 pt 宽 —— **未溢出**
- 对照组 C:`width:100%` —— 溢出(与第一轮一致)
- 依据补充:列宽用百分比时 Word 解析不可靠,实现侧优先用 pt;`table-layout` 仅 WPS/浏览器认,Word 靠 `mso-table-layout-alt:fixed`。

### 其它

- 行内代码灰底 + 细边框、黄色/浅蓝高亮(行内 `span` 的 `background-color`)在两端均保留。
- 表格的边框、表头底色、隔行底色在两端均保留(与第一轮一致)。

## 三、对渲染器的硬约束(实现据此)

1. **代码块、引用块一律单格表格承载**;底色、边框、内边距只写在 `td` 上,`pre`/`blockquote` 不再承担盒属性。
2. **禁止任何块级元素上的 `border-left`**(WPS 逐行框);左边线只能由 `td` 的 `border-left` + `mso-border-left-alt` 表达。
3. **表格宽度必须写具体 pt**(版心宽 = `contentWidthMm / 25.4 × 72`),并同时给 `table-layout:fixed`(WPS)与 `mso-table-layout-alt:fixed`(Word);禁用 `width:100%` / `width:auto` 作为唯一宽度来源。
4. **`table` 带 `border="0" cellspacing="0" cellpadding="0"`**;`td` 补 `mso-padding-alt`;表格补 `mso-table-lspace:0pt;mso-table-rspace:0pt`。
5. **中文字体除 `font-family` 外补 `mso-fareast-font-family`**(Word 认;WPS 未证实但无害)。
6. **全部样式内联**,不依赖 `<style>` 与 `class`。
7. **CF_HTML 头由 Chromium/Electron 自动生成**(`clipboard.write` / `writeHTML` 都会补 `Version:0.9` + 偏移 + `<!--StartFragment-->`)。**禁止手写头后再交给该 API** —— 会双重包裹,Word 把头部当正文。本项目 Electron 43:`clipboard.write({ text, html })` 可用。依据:Microsoft CF_HTML 规范 + W3C Clipboard APIs #193 + Electron breaking changes(44 起 `writeHTML` 移除)。
