# docs/ 文档索引

markdown-to-word:Markdown 转 Word / PDF 等格式的命令行工具。项目知识库:跨会话需要保留的结论、决策、手册都在本目录;本文件是索引与维护约定。

## 阅读路径(按场景)

- 新会话/新人上手 → `状态速查.md` → 本文件登记 → 按需查阅
- 搭环境/跑命令/找代码 → `开发者手册.md`
- 追溯「为什么这么设计/这个库有什么坑」→ `研究结论.md` / `架构决策.md`
- 排查故障 → `问题排查.md`(暂无,按需新建)
- 使用产品 → `用户手册.md`(暂无,按需新建)
- 看进度与计划 → `状态速查.md` / `路线图与迭代规划.md` / `CHANGELOG.md`

## 维护约定

- 条目格式遵循全局 AGENTS.md「调研/审查」节(结论/理由/来源/关联)。
- 累积型文件(研究结论/架构决策/CHANGELOG/问题排查):行数自然增长,不设上限、不做全量审计;新条目在上,同主题更新旧条目并置顶。
- 使用中顺手清理:读到已失效的研究结论 → 删除该条目;读到被推翻的架构决策 → 旧条目首行标「已被 YYYY-MM-DD 条目取代」,保留不删。
- 状态速查是每会话入口,保持 ≤80 行:收尾更新时顺手删除已关闭的打开事项与过期状态,超线当场瘦身。
