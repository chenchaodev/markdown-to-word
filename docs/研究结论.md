# 研究结论

### 2026-08-02 md→docx / md→pdf 库调研(规划选型用)
- 结论:docx 路线选 `docx`(9.7.1,2026-05-27)+ remark 自研渲染;pdf 路线选 `md-to-pdf`(5.2.5,2025-11-20)
- 理由:
  - docx:中文 eastAsia 一等支持(`font: { ascii, eastAsia, hAnsi }`),原生 ESM+TS,600 万下载/周,维护稳定;`@mohtasham/md-to-docx`(3.0.1,2026-07-31)仅暴露 fontFamily 无独立 eastAsia,留作回退;`markdown-docx`(vace)无字体入口,排除
  - md-to-pdf:一行 API 内置 markdown-it+语法高亮+分页;中文靠系统字体(Linux 缺 noto-cjk 会出方块)或 CSS `@font-face` 内嵌;`pdfmake` 需手动注册 TTF 字体,最不省事;Chromium 打印路线与 md-to-pdf 同坑且开发量更大
- 来源: @librarian
- 关联: docs/路线图与迭代规划.md
