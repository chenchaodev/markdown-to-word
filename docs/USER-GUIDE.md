# 用户手册

## 简介

Markdown 转换工具是一款 Windows 桌面应用,把 Markdown 文件转换成 **Word (.docx)** 或 **PDF** 文档。转换在本地完成,文件不上传,无隐私风险。

输出的是真正的 Word 文档(不是改后缀的网页),中文排版可控:字体、字号、行距、缩进、纸张、边距、分页、章节编号都可设置。

## 安装与卸载

- 安装:双击 `MarkdownToWord-Setup-<版本>.exe`,按向导下一步即可(可选择安装目录)
- 卸载:Windows「设置 → 应用」中找到 Markdown 转换工具,卸载即可

## 快速上手

1. **选择文件**:点击「选择文件」或直接把 Markdown 文件(支持多个)/文件夹拖入窗口
2. **选格式**:底部选择「Word (.docx)」或「PDF (.pdf)」
3. **点转换**:单文件点「开始转换」;多文件可选「批量转换」(每个文件一个文档)或「合并转换」(合成一个文档)

转换完成后会显示输出路径,可一键打开文件或所在文件夹。

## 界面说明

- **文件区**:拖入文件/文件夹,或点「选择文件」。单文件态有「追加文件」按钮;多文件态可追加、移除、拖拽调整顺序,列表按顺序转换。点击拖放区:单文件=更换,多文件=追加;拖入新文件始终=追加
- **进度区**:转换中显示进度条与百分比,可随时「取消」
- **结果区**:常驻显示「成功 N / 失败 M」、输出路径;失败时显示原因,可展开查看警告(如图片缺失)
- **快捷键**:`Ctrl+O` 添加文件、`Ctrl+Enter` 开始转换(底部有可见提示;多文件时 Ctrl+Enter=批量转换)
- **最近转换**:转换后显示最近记录,单击条目=加载到文件列表(可先改设置再转),双击条目=直接重转;条目右侧「仅加载」按钮=仅载入列表不转换
- **设置**:「设置」抽屉内含多子组(模板 / 页面 / 排版 / 页眉页脚 / 文字水印 / 导出)+ 界面语言与外观主题,改动即时生效并自动保存

## 转换模式

| 模式 | 触发 | 输出 |
| ---- | ---- | ---- |
| 单文件 | 选择 1 个文件 → 开始转换 | 源文件同名换扩展名 |
| 批量 | 选择多个文件 → 批量转换 | 每个文件单独生成一个文档 |
| 合并 | 选择多个文件 → 合并转换 | 所有文件按顺序合成一个文档,文件名含「-合并」;合并产物含单一总目录,覆盖全部源文件标题(可点击跳转) |

**重名保护**:输出文件已存在时自动加序号(如 `文档 (2).docx`),绝不覆盖原有文件。

## 转换预检报告

开始转换前(单文件 / 批量 / 合并均触发),程序会先做一次预检,扫描常见问题:

- 缺失的本地图片(相对路径找不到文件)
- 悬空的交叉引用(如 `[章节](#sec:x)` 但文中无对应 `{#sec:x}`)
- 未标注语言的代码块(``` 后无语言标识)

若发现问题,会弹出带「校」印章的预检报告,逐条列出警告;点「继续转换」正常出文件,点「取消」中止。干净文档(无上述问题)则不弹报告,静默直接转换。批量/合并转换时,所有文件的警告会聚合后弹一次报告。

## 设置项

### 模板预设

模板预设位于「设置」面板「模板」子组:默认 / 学术论文 / 商务简报,选择即覆盖排版与页面设置;可「另存为预设」保存当前设置(上限 10 个),自定义预设可删除;支持预设 JSON 导入/导出。另可「导入 Word 模板」:在「模板」子组动作行点「导入 Word 模板…」选择 .docx 文件,程序提取其正文西文/中文字体、正文字号、纸张与边距并映射回当前设置(浅导入 v1,不含颜色等深导入);导入不与预设冲突、不写入预设,重启后保留。

### 页面设置
| 设置 | 说明 |
| ---- | ---- |
| 纸张 | A4 / A3 / A5 / Letter / Legal |
| 方向 | 纵向 / 横向 |
| 边距 (mm) | 上/下/左/右,范围 0–1000 |
| 每个一级标题前分页 | 每个 `# 标题` 前插入分页符 |
| 自动生成目录 | 默认开;正文含标题时生成目录页(Word 打开即见,无需更新域) |

### 排版
| 设置 | 说明 |
| ---- | ---- |
| 西文字体 | 正文中的字母与数字(如 Calibri、Times New Roman) |
| 中文字体 | 正文中的汉字(如微软雅黑、宋体) |
| 正文字号 | 8–24 pt |
| 行距 | 1.0–2.5 倍 |
| 首行缩进 2 字符 | 中文正文常见排版 |
| 两端对齐 | 关闭后为左对齐 |
| 章节自动编号 | 标题自动生成「1 / 1.1 / 1.1.1」编号 |
| 图/表题注自动编号 | 「图: 标题」/「表: 标题」前缀行自动编号(见下方题注说明) |
| 公式编号 | 默认开;关闭后公式不编号,引用保持原文本 |
| 目录模式 | 静态目录(默认,打开即见、无页码、免更新)/ Word 域目录(打开时提示更新域,更新后目录显示真实页码并可点击跳转);PDF 目录始终带页码 |
| 标题排版 | 标题字号缩放、标题间距,各三档(紧凑/标准/舒展),docx 与 PDF 一致 |

### 页眉页脚

页眉页脚位于「设置」面板(带「不入预设」徽标,套用预设不改变):

| 设置 | 说明 |
| ---- | ---- |
| 页眉模式 | 默认(标题居中)/ 自定义(自定义文字 + 可选 logo)/ 无 |
| 自定义文字 | 页眉显示的固定文字(自定义模式下) |
| logo | 页眉左侧 logo 图片(支持常见位图;读取失败降级无 logo 并提示) |
| 布局 | 居中 / 左右分栏(logo 左 + 文字右) |
| 页脚开关 | 开启后在页脚显示「第 X / 共 X 页」页码 |

Word 与 PDF 双格式页眉页脚观感一致(字号/灰度对齐)。

### 文字水印

文字水印位于「设置」面板「文字水印」子组(带「不入预设」徽标):

| 设置 | 说明 |
| ---- | ---- |
| 水印文字 | 每页叠加的文字内容;置空则不显示水印 |
| 角度 | 水印旋转角度(默认对角) |
| 不透明度 | 水印透明度 |
| 浅灰 | 开启→浅灰经典观感,关闭→沿用正文字色 |

水印旋转置底,不遮挡正文;「恢复默认」后复位为默认(空文字),套用模板预设不改变水印。

### 导出
| 设置 | 说明 |
| ---- | ---- |
| 输出目录 | 默认「与源文件相同目录」,可改为固定目录(须为绝对路径) |
| 导出后 | 转换完成后:不自动执行 / 打开所在文件夹 / 打开文件 |
| 转换完成弹窗提示 | 转换完成后弹窗提示(可关闭) |
| PDF CSS 导入 | 导入 CSS 文件作为 PDF 样式模板,追加到默认样式之后覆盖(仅 PDF 路线生效) |

### 外观主题

浅色 / 深色 / 跟随系统 三态切换,即时生效并记忆;深色下界面整体变色(背景/文字/按钮/弹窗/列表),预览错误页配色同步适配。

### 界面语言

界面语言由内置语言注册表驱动,当前支持三种:中文 / English / 日本語(个别缺失文案自动回退英文,不会显示乱码键名)。切换即时生效并记忆(下次启动保持上次选择)。历史版本中保存过的韩语/法语/俄语偏好,升级后自动回退为中文,其余设置不受影响。

## 支持的 Markdown 语法

| 语法 | 支持 |
| ---- | ---- |
| 标题、段落、粗体/斜体、行内代码、链接、引用 | ✅ |
| 无序/有序/嵌套列表 | ✅ |
| 表格、代码块(已知语言语法高亮,未知/无语言降级等宽)、本地图片 | ✅ |
| GFM 删除线、任务列表(☐/☑) | ✅ |
| 脚注 `[^1]` | ✅ |
| 批注 `[锚定文本]{批注=内容}` | ✅ docx 原生批注;pdf 原样输出 |
| 公式 `$...$` / `$$...$$` / ` ```math ` | ✅ |
| Mermaid 图表 ` ```mermaid ` | ✅ 围栏内写 Mermaid 语法,导出为图表(docx 嵌入图片 / PDF 矢量渲染);语法错误时降级为代码块并提示 |
| 目录 | 自动生成(见「设置 → 排版 → 目录模式」):静态目录打开即见、无页码、免更新;Word 域目录打开时提示更新域,更新后显示真实页码并可跳转;PDF 目录始终带页码 |
| 显式分页符 `<!-- page-break -->` | ✅ 在源码中插入该注释即强制分页 |
| 图/表题注 | `图: 说明文字` / `表: 说明文字` 前缀行自动编号(图 1、图 2…;表 1、表 2…) |
| 图片尺寸属性 `![alt](src){width=50%}` | ✅ 见下方「图片尺寸属性」说明 |

其他说明:
- **图片**:本地相对路径图片自动嵌入;网络图片自动下载嵌入(失败时保留链接并提示)
- **图片尺寸属性**:在图片后紧跟 `{width=50%}` / `{width=300}` / `{height=200}` / `{width=50% height=30%}` 可控制图片尺寸——百分比相对正文内容宽度,纯数字为像素;只给一维时另一维按原图宽高等比缩放,两维都给时按给定值(不保持比例)。属性须紧跟图片且直到段尾(其后不能再有其他文字);独立成段的图片会自动居中显示。非法值(负数/非数值/百分比超 100)忽略该属性并给出警告,图片按默认尺寸转换
- **文件信息**:Markdown 文件开头的 `---` 区域可写 `title` / `author` / `date`,用于封面与页眉
- **编码**:自动识别 UTF-8 / UTF-16 / GBK 编码,无需手动处理
- **题注**:独立成行且以「图: 」或「表: 」开头的段落视为题注,自动按类型编号;Word 中为静态文字,可直接编辑(如不想要编号,删除编号文字即可)
- **公式编号**:排版设置中的「公式编号」开关,默认开;关闭后公式不编号、引用保持原文本

## 在 Word / WPS 中

- **目录**模式相关:默认「静态目录」为转换时生成的静态内容,Word 打开即见、无页码、无需更新;「Word 域目录」模式下 Word/WPS 打开会提示更新域,点「更新域」后目录显示真实页码并可点击跳转;PDF 侧目录始终带正确页码(与正文一致)
- **页码**为原生 Word 域(页眉页脚);**章节编号**为原生 Word 结构,可正常编辑
- **题注编号**为静态文字,直接可编辑
- **PDF 书签**:PDF 侧边栏自动带书签大纲,可直接跳转章节

## 常见问题

**Q:转换失败,提示「编码无法识别」?**
A:支持 UTF-8 / UTF-16 / GBK(含 GB18030)常见编码,极少无法识别;可将文件另存为 UTF-8 后重试。

**Q:输出到了奇怪的位置?**
A:默认输出在源文件同目录;若源文件路径过长(超过约 250 字符)会回落输出到源文件所在目录并提示,可改用「输出目录」设置固定位置。

**Q:PDF 里的中文是方块?**
A:Windows 下会自动使用系统字体(微软雅黑),一般不会出现;若在极精简系统上异常,请安装中文字体。

**Q:生成的 Word 打开时提示更新域?**
A:仅当「设置 → 排版 → 目录模式」选择「Word 域目录」时,Word/WPS 才会提示更新域(点「是」显示真实页码);默认「静态目录」模式打开即见、无需更新。页码本身为原生 Word 域(页眉页脚),章节编号为原生结构,均可正常编辑。

**Q:公式没有编号?**
A:检查「设置 → 排版 → 公式编号」是否开启(默认开);只有 `$$...$$` 独立公式块参与自动编号,行内 `$...$` 不编号;关闭开关后引用也会保持原文本。

**Q:图片没有显示在文档里?**
A:转换完成后的警告列表会列出原因——本地图片请确认相对路径正确(相对于 md 文件所在目录);网络图片需可访问,下载失败时保留原文链接;无法识别格式的图片文件会被跳过并提示。

**Q:安装时 Windows 提示「已保护你的电脑」(SmartScreen)?**
A:本应用未做代码签名(离线本地工具,不采集任何数据)。点击「更多信息」→「仍要运行」即可继续安装;也可只从 GitHub Releases 官方页面下载安装包。
