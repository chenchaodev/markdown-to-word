# 用户手册

## 简介

Markdown 转换工具是一款 Windows 桌面应用，把 Markdown 文件转换成 **Word (.docx)** 或 **PDF** 文档。转换在本地完成，文件不上传，无隐私风险。

输出的是真正的 Word 文档（不是改后缀的网页），中文排版可控：字体、字号、行距、缩进、纸张、边距、分页、章节编号都可设置。

## 安装与卸载

- **安装**：双击 `MarkdownToWord-Setup-<版本>.exe`，按向导下一步即可（可选择安装目录）
- **卸载**：Windows「设置 → 应用」中找到 Markdown 转换工具，卸载即可

## 快速上手

### 基本转换

1. **选择文件**：点击「选择文件」或直接把 Markdown 文件（支持多个）/文件夹拖入窗口
2. **选格式**：底部选择「Word (.docx)」或「PDF (.pdf)」
3. **点转换**：单文件点「开始转换」；多文件可选「批量转换」（每个文件一个文档）或「合并转换」（合成一个文档）

转换完成后会显示输出路径，可一键打开文件或所在文件夹。

### 剪贴板直转

主界面空态/拖放区显示「粘贴 Markdown 转换」按钮：

- **粘贴文本**：点击按钮后读取剪贴板 Markdown 文本直接转换
- **粘贴路径**：剪贴板为文件路径时，复用拖入队列逻辑
- **空/非文本**：给出提示，不执行转换

适合从 AI 工具（ChatGPT、Claude 等）复制 Markdown 输出后直接转换。

### 成书向导

点击「成书向导」按钮，七步引导式串联所有功能：

| 步骤 | 内容 | 说明 |
| ---- | ---- | ---- |
| ① 模板/预设 | 选择内置预设或导入 Word 模板 | 覆盖字体、字号、页面设置 |
| ② 封面页 | 输入标题/作者，生成独立封面 | docx 封面节 / PDF HTML 封面 |
| ③ 页眉页脚 | 默认/自定义/无三种模式 | 支持 logo 和左右分栏 |
| ④ 水印 | 文字/角度/不透明度/浅灰 | Word 旋转置底，PDF 固定覆盖层 |
| ⑤ 合并源 | 多选 Markdown + 排序 | 以 page-break 拼接 |
| ⑥ 目录/页码 | 开 TOC + 选择模式 | 静态或 Word 域目录 |
| ⑦ 输出 | 单个 docx/pdf | 含封面页和完整目录 |

全程无需打开设置面板即可产出复杂成书。

### 首次启动引导

首次启动时会出现「选预设 → 向导 → 转换」引导路径，帮助快速上手。可跳过，不强制打开设置面板；非首次启动不再出现。

## 界面说明

### 主界面布局

- **标题栏**：品牌区 + 格式切换（Word/PDF）+ 设置按钮 + 关于按钮
- **文件区**：拖入文件/文件夹，或点「选择文件」
- **快速参数条**：常用设置（纸张、方向、字体）即时调整
- **转换按钮**：开始转换（底部常驻）
- **最近转换**：转换后显示最近记录

### 文件操作

- **单文件态**：显示「追加文件」按钮，点击追加更多文件
- **多文件态**：可追加、移除、拖拽调整顺序，列表按顺序转换
- **点击行为**：单文件=更换文件，多文件=追加文件；拖入新文件始终=追加
- **快捷键**：`Ctrl+O` 添加文件、`Ctrl+Enter` 开始转换

### 最近转换

- **单击条目**：加载到文件列表（可先改设置再转）
- **双击条目**：直接重转
- **「仅加载」按钮**：仅载入列表不转换
- **「清空最近」**：清空最近记录

### 设置面板

「设置」抽屉内含 6 组标签页导航：

| 标签 | 内容 |
| ---- | ---- |
| 01 预设 | 模板预设选择、另存为、导入/导出、导入 Word 模板 |
| 02 排版 | 字体、字号、行距、缩进、对齐、编号、目录、标题排版、AI 清理、Obsidian 兼容 |
| 03 页眉页脚与水印 | 页眉模式、logo、布局、页脚开关、水印设置 |
| 04 编号与目录 | 章节编号、题注编号、公式编号、目录模式 |
| 05 转换 | 输出目录、导出后行为、转换完成弹窗、PDF CSS 导入 |
| 06 应用 | 界面语言、外观主题 |

改动即时生效并自动保存。

## 转换模式

| 模式 | 触发 | 输出 |
| ---- | ---- | ---- |
| 单文件 | 选择 1 个文件 → 开始转换 | 源文件同名换扩展名 |
| 批量 | 选择多个文件 → 批量转换 | 每个文件单独生成一个文档 |
| 合并 | 选择多个文件 → 合并转换 | 所有文件按顺序合成一个文档，文件名含「-合并」；合并产物含单一总目录，覆盖全部源文件标题（可点击跳转） |

**重名保护**：输出文件已存在时自动加序号（如 `文档 (2).docx`），绝不覆盖原有文件。

## 转换预检报告

开始转换前（单文件 / 批量 / 合并均触发），程序会先做一次预检，扫描常见问题：

- 缺失的本地图片（相对路径找不到文件）
- 悬空的交叉引用（如 `[章节](#sec:x)` 但文中无对应 `{#sec:x}`）
- 未标注语言的代码块（`` ``` `` 后无语言标识）

若发现问题，会弹出带「校」印章的预检报告，逐条列出警告；点「继续转换」正常出文件，点「取消」中止。干净文档（无上述问题）则不弹报告，静默直接转换。

批量/合并转换时，所有文件的警告会聚合后弹一次报告。

### 页眉页脚

页眉页脚位于「设置」面板（带「不入预设」徽标，套用预设不改变）：

| 设置 | 说明 |
| ---- | ---- |
| 页眉模式 | 默认（标题居中）/ 自定义（自定义文字 + 可选 logo）/ 无 |
| 自定义文字 | 页眉显示的固定文字（自定义模式下） |
| logo | 页眉左侧 logo 图片（支持常见位图；读取失败降级无 logo 并提示） |
| 布局 | 居中 / 左右分栏（logo 左 + 文字右） |
| 页脚开关 | 开启后在页脚显示「第 X / 共 X 页」页码 |

Word 与 PDF 双格式页眉页脚观感一致（字号/灰度对齐）。

### 文字水印

文字水印位于「设置」面板「文字水印」子组（带「不入预设」徽标）：

| 设置 | 说明 |
| ---- | ---- |
| 水印文字 | 每页叠加的文字内容；置空则不显示水印 |
| 角度 | 水印旋转角度（默认对角） |
| 不透明度 | 水印透明度 |
| 浅灰 | 开启→浅灰经典观感，关闭→沿用正文字色 |

水印旋转置底，不遮挡正文；「恢复默认」后复位为默认（空文字），套用模板预设不改变水印。

### 导出

| 设置 | 说明 |
| ---- | ---- |
| 输出目录 | 默认「与源文件相同目录」，可改为固定目录（须为绝对路径） |
| 导出后 | 转换完成后：不自动执行 / 打开所在文件夹 / 打开文件 |
| 转换完成弹窗提示 | 转换完成后弹窗提示（可关闭） |
| PDF CSS 导入 | 导入 CSS 文件作为 PDF 样式模板（仅 PDF 路线生效） |

### 外观主题

浅色 / 深色 / 跟随系统 三态切换，即时生效并记忆；深色下界面整体变色（背景/文字/按钮/弹窗/列表），预览错误页配色同步适配。

### 界面语言

界面语言由内置语言注册表驱动，当前支持三种：中文 / English / 日本語（个别缺失文案自动回退英文，不会显示乱码键名）。切换即时生效并记忆（下次启动保持上次选择）。

## 图片尺寸属性

在图片后紧跟属性可控制图片尺寸：

```markdown
![图片描述](图片路径){width=50%}
![图片描述](图片路径){width=300}
![图片描述](图片路径){height=200}
![图片描述](图片路径){width=50% height=30%}
```

- **百分比**：相对正文内容宽度
- **纯数字**：像素
- **只给一维**：另一维按原图宽高等比缩放
- **两维都给**：按给定值（不保持比例）
- **独立成段图片**：自动居中显示
- **非法值**：忽略属性并给出警告

## 题注说明

独立成行且以「图: 」或「表: 」开头的段落视为题注：

- 自动按类型编号（图 1、图 2…；表 1、表 2…）
- Word 中为静态文字，可直接编辑
- 如不想要编号，删除编号文字即可

## 在 Word / WPS 中

- **目录**：默认「静态目录」为转换时生成的静态内容，Word 打开即见、无页码、无需更新；「Word 域目录」模式下 Word/WPS 打开会提示更新域，点「更新域」后目录显示真实页码并可点击跳转
- **页码**：原生 Word 域（页眉页脚）
- **章节编号**：原生 Word 结构，可正常编辑
- **题注编号**：静态文字，直接可编辑
- **PDF 书签**：PDF 侧边栏自动带书签大纲，可直接跳转章节

## 常见问题

### 转换相关

**Q: 转换失败，提示「编码无法识别」？**
A: 支持 UTF-8 / UTF-16 / GBK（含 GB18030）常见编码，极少无法识别；可将文件另存为 UTF-8 后重试。

**Q: 输出到了奇怪的位置？**
A: 默认输出在源文件同目录；若源文件路径过长（超过约 250 字符）会回落输出到源文件所在目录并提示，可改用「输出目录」设置固定位置。

**Q: PDF 里的中文是方块？**
A: Windows 下会自动使用系统字体（微软雅黑），一般不会出现；若在极精简系统上异常，请安装中文字体。

**Q: 公式没有编号？**
A: 检查「设置 → 排版 → 公式编号」是否开启（默认开）；只有 `$$...$$` 独立公式块参与自动编号，行内 `$...$` 不编号；关闭开关后引用也会保持原文本。

**Q: 图片没有显示在文档里？**
A: 转换完成后的警告列表会列出原因——本地图片请确认相对路径正确（相对于 md 文件所在目录）；网络图片需可访问，下载失败时保留原文链接；无法识别格式的图片文件会被跳过并提示。

### 目录相关

**Q: 生成的 Word 打开时提示更新域？**
A: 仅当「设置 → 排版 → 目录模式」选择「Word 域目录」时，Word/WPS 才会提示更新域（点「是」显示真实页码）；默认「静态目录」模式打开即见、无需更新。页码本身为原生 Word 域（页眉页脚），章节编号为原生结构，均可正常编辑。

### 安装相关

**Q: 安装时 Windows 提示「已保护你的电脑」(SmartScreen)？**
A: 本应用未做代码签名（离线本地工具，不采集任何数据）。点击「更多信息」→「仍要运行」即可继续安装；也可只从 GitHub Releases 官方页面下载安装包。

**Q: 如何升级到新版本？**
A: 本软件暂未内置自动更新。前往 [GitHub Releases](https://github.com/chenchaodev/markdown-to-word/releases) 下载最新的 `MarkdownToWord-Setup-<版本>.exe`，运行安装向导覆盖安装即可；设置文件位于本机用户数据目录，重新安装不会清除，你的偏好会保留。

### 设置相关

**Q: 如何切换界面语言？**
A: 打开「设置」抽屉，在「应用」分组中找到「界面语言」，可选 中文 / English / 日本語；切换即时生效并自动记忆，下次启动保持上次选择。个别缺失文案会自动回退英文，不会显示乱码键名。

**Q: 设置保存在哪里？如何重置？**
A: 所有设置保存在本机用户数据目录的 `settings.json`（Windows 上通常位于 `%APPDATA%\markdown-to-word\settings.json`），不会上传。多数分组内有「恢复默认」可单项重置；若要彻底重置，关闭软件后删除该 `settings.json`，下次启动会以默认设置重新生成（不影响安装目录）。

## 已知限制

- **仅支持 Windows**：当前只发布 Windows 桌面版，无 macOS / Linux 构建。
- **未做代码签名**：作为离线本地工具，安装包未做代码签名，Windows SmartScreen 可能提示「已保护你的电脑」（见上方常见问题）；只从 GitHub Releases 官方页面下载安装包即可放心安装。
- **内联 HTML 仅白名单**：Markdown 中的内联 HTML 仅允许白名单内的无属性标签（`strong` `b` `em` `i` `u` `s` `del` `code` `kbd` `sub` `sup` `mark` `br` `span`），带属性的标签或白名单外的标签会被忽略。复杂排版请改用原生 Markdown 语法。
- **网络图片依赖可达性**：网络图片在转换时下载嵌入，需可访问；下载失败时保留原链接并提示。
- **docx 侧任务列表无 checkbox 视觉**：设计如此（与 pdf ☐/☑ 字符替代不同）。
