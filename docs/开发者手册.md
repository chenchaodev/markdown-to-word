# 开发者手册

## 环境
- Node >= 18(ESM)
- npm 源:npmmirror(见根 `.npmrc`,勿回退)

## 命令
| 命令 | 用途 |
| ---- | ---- |
| `npm install` | 安装依赖(首次先 `npm install -D typescript @types/node`) |
| `npm run typecheck` | TS 类型检查(`tsc --noEmit`) |
| `npm run build` | 构建到 `dist/`(`tsc`) |

## 代码地图
- `src/`:转换逻辑与 CLI(开发开始后填充)
- `docs/`:项目文档

## 验证方式
- 类型检查与构建通过后再提交;打包/构建类改动必须实际构建验证
