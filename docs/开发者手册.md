# 开发者手册

## 环境
- Node >= 18(ESM)
- npm 源:npmmirror(见根 `.npmrc`,勿回退)
- Electron 二进制镜像(勿回退,装 electron/打包前设置):
  - `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`
  - `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`

## 命令
| 命令 | 用途 |
| ---- | ---- |
| `npm install` | 安装依赖(首次先 `npm install -D typescript @types/node`,Electron 单独装并设镜像) |
| `npm run typecheck` | TS 类型检查(`tsc --noEmit`) |
| `npm run build` | 构建 core/cli 到 `dist/`(`tsc`) |
| `node scripts/g1-verify.mjs` | 生成全要素样例 docx(需先 build) |
| `npm run dev` | 启动 Electron 开发(G2 起) |
| `npm run dist` | electron-builder 打包 NSIS 安装包(G5) |

## 代码地图
- `src/core/`:纯转换逻辑,无 IO,可测试
  - `parse.ts`:remark + remark-gfm → mdast AST
  - `docx/theme.ts`:字体/样式集中配置(eastAsia 中文)
  - `docx/render.ts`:AST → docx(标题/段落/列表/表格/代码块/引用/图片/行内样式)
- `src/main/`:Electron 主进程
  - `index.ts`:窗口创建、dialog 选择文件、IPC 注册(`--smoke` 冒烟模式)
  - `preload.cts`:contextBridge 白名单暴露 `window.api.openMarkdownDialog`(编译为 CJS)
- `src/renderer/`:GUI UI(vanilla TS + 原生 DOM)
  - `index.html` / `style.css`:Win11 浅色风格界面,含 CSP meta
  - `renderer.ts`:文件选择/拖放/格式单选/状态反馈
- `src/cli/`:调试/回归通道(非交付物,待建)
- `scripts/`:g1-verify.mjs(全要素样例)、copy-renderer.mjs(静态资源拷贝)
- `docs/`:项目文档

## 验证方式
- 类型检查与构建通过后再提交;打包/构建类改动必须实际构建验证
- docx/PDF 验收样例固定含中英混排,生成后人工打开检查中文渲染
