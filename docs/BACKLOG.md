# 项目 Backlog（BACKLOG.md）

> 更新：2026-09-25（结构：分类 × 处置双维，替上一版处置四层结构）
> **性质**：所有新需求/候选/曾砍重提先在此登记（分类 + 处置 + 业务价值/工作量）；**经用户确认后移入 `ROADMAP.md`「当前待办」**再进入开发。ROADMAP 只放已确认项；暂缓/不做等处置结论集中本文件，不散写 ROADMAP/STATUS。规则见项目 `AGENTS.md`「流程」与全局 `WORKFLOW-PLAN.md` 阶段 0/1。
> **结构**：`Backlog 任务` 按分类分节（功能新增 / 体验优化 / 架构优化·技术债 / 防御·安全），处置见列；非任务备忘集中 `维持人工·已知限制` 节。
> **口径**：业务价值 = 对用户/市场的价值（高/中/低，不考虑历史排除因素）；工作量 = S（≤3 文件、天级）/ M（周级）/ L（多周或有架构风险）。
> **处置列**：待拍板（未拍板、可晋升入 ROADMAP）/ 渐进执行中（已启动、无排期）/ 暂缓（记录不排期、可重新提案）/ 已明确不做（原结论在案、可重新拍板晋升）。
> **排序**：每分类内按处置带（待拍板 → 渐进执行中 → 暂缓 → 已明确不做），同带按业务价值降序、工作量升序。
> 已完成出池（历史见 CHANGELOG 与 ROADMAP「已完成」节）：成书向导、剪贴板直转/拖放增强、GUI 易用反制 AIDOC、契约类型归位、测试盲区盘点、开箱中文排版预设（3.7.0 首轮）。
