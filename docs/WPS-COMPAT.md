# WPS 兼容矩阵

> 2026-08-16 建立。目的:Word/WPS 双实测清单化,守护既有功能——docx 产物在 Word 与 WPS 中的表现逐项核对,差异/问题记录在案,修复排后续迭代。pdf 为标准格式(WPS 打开 pdf 无兼容风险),矩阵聚焦 docx 产物。

## 实测指引

1. 用 `test/fixtures/acceptance/` 验收样例(gen-fixtures 生成,覆盖各功能域)或自写 md 转换 docx
2. Word 打开产物,按下方矩阵逐项核对,更新「Word」列
3. WPS 打开同一产物,逐项核对,更新「WPS」列
4. 记录格式:✅ 通过 / ⚠️ 问题(现象 + 复现步骤 + 截图) / ⬜ 待测
5. 问题项 → 记入「问题记录」节,修复排后续迭代

## 历史修复(已解决,防回归)

- 0.20.0:WPS 公式段显示异常(公式左侧出现 TeX 源码文本)——公式编号段输出裸 `<w:tab/>`(OOXML 中 w:tab 属 run 内元素)→ WPS 解析异常把 m:oMath 降级为纯文本;修复:Tab 包进 `TextRun({ children: [new Tab()] })`
- 0.20.0:书签 w:id 冲突——docx 库 Bookmark 组件每实例独立 id 计数器,文档内所有书签 w:id 恒为 1;修复:改用 BookmarkStart/BookmarkEnd + 模块级自增计数器
- 0.9.1:PDF 书签点击不跳转(全部回退首页)——destKeyText 对 PDFName key 解码错误;修复:decodeText() 还原百分号形式再解码
