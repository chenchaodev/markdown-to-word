## 背景

触发点是用户实测反馈侧边栏书签为空（原文「决策」行）。方案可行性由前置产物结构解析确认：实测合并 PDF 含 18 个 Link 注释与 /Dests 命名目标，即锚点链接存在而缺的是大纲树 —— 缺口定位到结构而非渲染。范围被红线限死：书签只做 H1/H2 最小版或砍，脚注与页眉页脚+页码随后。来源：自查（用户反馈 + 产物解析）。
