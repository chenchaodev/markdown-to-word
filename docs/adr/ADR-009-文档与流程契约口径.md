# ADR-009 · 文档与流程契约口径

| 项 | 值 |
|---|---|

## 背景

本条是 campaign 裁决 D-01~D-05 的升格（来源行）。五条决定各自对应一条挡路的既有约束（原文「理由」行）：① 统一 archive 命名与按发布口径重写 CHANGELOG，会被「archive 只增不改」与「CHANGELOG 容量上限」两条约束挡路，故一并豁免；② 需求入口存在双源（并行的项目级候选池文件 + `docs/REQ.md`），与全局模板的「单一入口」冲突，故废除前者；③④ 两份旧全局指南（Windows 平台坑、CHANGELOG 写法）已分别并入 `ENV-GUIDE.md` / `PUBLISH-GUIDE.md`，旧名在全局已不存在 —— 补建会造成第二份真源，沿用旧名则成死指针，故一律改指；⑤ 验收矩阵的「不删行」判读为「不删功能点行」，要保住的是跨迭代验收资产而非行下散文块。已知代价：archive 原文不再逐份留痕。

## 决定

### 2026-09-26 19:40:00 文档与流程契约口径(ADR-009)
- 决策:① 豁免「archive 只增不改 / 原文留痕」与「CHANGELOG 容量上限」;② 需求入口单源为 `docs/REQ.md` 台账,废除那份并行的项目级候选池文件;③ 旧的两份全局指南(Windows 平台坑、CHANGELOG 写法)已分别并入 `ENV-GUIDE.md` / `PUBLISH-GUIDE.md`,项目侧**改指**而非补建;④ 旧小节名以现行全局节名为准;⑤ 验收矩阵的「不删行」判读为「不删功能点行」
- 理由:① 统一 archive 命名与按发布口径重写 CHANGELOG 会被这两条约束挡路;② 双源与全局模板的「单一入口」冲突;③④ 旧名在全局已不存在,补建造成第二份真源、沿用旧名即死指针;⑤ 要保住的是跨迭代验收资产,行下散文块不在其列
- 代价:archive 原文不再逐份留痕(决策与事实已分别升格到本文件与 `docs/archive/`)
- 验证:`grep` 核对零悬空指针;三处编号台账人工对表
