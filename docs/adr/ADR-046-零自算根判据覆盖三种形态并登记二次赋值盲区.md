## 决定

ADR-040 的「零自算根」判据**已覆盖三种此前登记为缺口的形态**，而**唯一剩下的真缺口（二次赋值）有意不补**。本决策只做两件事：关闭 ADR-044 遗留的盲区登记、把新发现的盲区写成**已知不补**而非门禁规则。

具体：

1. **三种形态已覆盖并有夹具守住**（判据侧已落地，见下节「背景」的提交）：
   - **多行连写** —— 靠 `LITERAL_CHAIN_RE` + `callArgs` 的括号配平，跨行不漏
   - **`.cjs` 隐式 `__dirname`** —— 靠 `isCjs` 特判，不再依赖 `ROOT_COMPUTE_PATTERNS` 那四条逐行正则（那四条对 `.cjs` 的 `__dirname` 命中数恒为 0）
   - **字符串字面量遮罩** —— 靠 `insideString` + `lexSource`，夹具串内/模板串内/注释内的写法一律判绿，真代码里的 `'..'` 正常参与计数

2. **「二次赋值」盲区有意不补**，理由记在判据源文件旁的注释里（写「为什么」而非「是什么」）。

## 背景

ADR-040 的「零自算根」判据长期被记为「只认链式单表达式」，缺口登记在别处。逐面实测（用判据自己导出的 `findRootComputes`，不复制匹配逻辑）后发现：**三种形态早已落地并有夹具守住**，只剩一个真缺口，且那个缺口当前树上零活样本。本决策据此关闭旧登记、把新缺口写成「已知不补」。

`analyzeRootComputes(root)` 在当前树上返回 `[]` —— **全仓 529 个文件零命中**。这意味着判据能力从未被任何真实文件验证过能触发，只有 `selfCheckRootComputes` 的合成夹具在守。

三种形态的覆盖由提交 `654da05`「自算根判据覆盖两语句式等四种形态」落地（含 `collectDepthHits` / `ORIGIN_BASE_CALL_RE` / `LITERAL_CHAIN_RE` / `insideString` / `isCjs`，净增 245 行）。

### 为什么现在做这个决策

台账把已建成的形态记成待建，会让人重复实现一遍；而真实剩下的那个缺口又不足以支撑建判据。两者都需要一次实测定性，否则下一轮仍会按错误前提派工。

### 「二次赋值」为什么不补

盲区内容：origin 只做**一层**传播。`const a = join(here,'..'); join(a,'..')` 不判红，而同样深度的单跳 `join(here,'..','..')` 判红。

唯一能判红的构造：`relPath` 深 2（两跳各 ups 1）⇒ 该形态 GREEN，同文件单跳形态 RED。

不补的三条理由：

1. **零活样本**。把传递闭包原型跑全树（含 `src/**` 的 `.ts`，共 381 文件），真实代码 **0 命中**；唯一命中落在判据自身的规则定义处（即 `ROOT_COMPUTE_SELF_EXEMPT` 所豁免的那个文件）。按 ADR-042，零违规的规则是**拿维护成本换零收益**。
2. **传递传播会造假阳性**。传播会丢失「中间变量是目录还是文件路径」的语义：`const a = join(here,'..','x'); join(a,'..')`（中间变量带下钻段）现在判绿，若加传播就会被误判红 —— 那是在惩罚合法写法。
3. **没有绕过动机**。本仓纪律下不存在「为骗过门禁而写两跳」的写法（ADR-040 零豁免，每个根决策都有行内注释论证）。

**写入速率不构成建它的理由** —— 速率高说明需要覆盖面，不说明需要补一个零样本的窄面。

### 为什么标取代而不是改 ADR-044

ADR-044 后果节登记的「`__dirname` 正则盲区，登记在 REQ-124 处理」是一项**未决登记**。它已被关闭。按「新立一份标取代，不改写旧条」的规则，由本决策标记取代关系；ADR-044 正文不动。

## 备选方案

- **把「二次赋值」写成门禁规则** —— 否决。那会得到一条**只在自身豁免文件里命中自己**的判据，且带来上述假阳性。
- **把「零触发」本身当缺陷去修** —— 否决为**本决策范围外**。真实代码零违规是仓库现状的正常态（判据的职责是拦住违规，不是保证有违规）；夹具与真实代码之间无交叉验证这一点，已单独登记跟踪，不在本决策处理。
- **放宽 `ORIGIN_BASE_CALL_RE` 使 origin 可不在首参** —— 否决。`src/**` 与 `.ts` 全量实测 0 命中，且其间的 `resource-dirs.ts` 属该形态是**既定决策**（见下节）。

## 后果

- **一个已登记的盲区关闭**：ADR-044 遗留的 `__dirname` 正则盲区不再挂账。
- **一个新盲区以「已知不补」形式登记**：它在判据源文件旁，且必须写明不补的理由与唯一的可判反例构造，使将来想补的人不必重新推导。
- **判据仍只被夹具验证**：真实代码零触发这件事**没有被本决策改变**，已单独跟踪。误读本决策为「判据已被真实代码验证」是错的。
- **`resource-dirs.ts` 属刻意排除的形态**：该文件的 origin 经函数形参传递，而 `collectOrigins` 只收 `const/let/var` 声明。这是判据的**既定边界**（判红它只会逼人改函数签名），不是疏漏；该处由 `test/main/resource-dirs.test.js` 的三态断言看守。
