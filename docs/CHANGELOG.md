## [3.16.0] - 2026-10-01

### 安装与分发

## [3.15.1] - 2026-09-30

### 修复

- 图 / 表题注的字号在两种导出下原本不一致：Word 跟随正文字号，PDF 固定 10pt。两者都跟随正文字号，默认正文字号下为 11pt。
- 代码的字号在两种导出下原本不一致：Word 固定 10pt，行内代码与代码块同号；PDF 行内为正文字号的 0.9 倍，代码块固定 9.5pt。两者都跟随正文字号，并保留行内代码大于代码块的层次。
- 默认正文字号下，代码字号为 PDF 10.8pt / 9.5pt，Word 按字号粒度取整为 11pt / 9.5pt。
- 标题里的行内代码原本会跟着标题一起放大，PDF 导出中二级标题内约 15pt。这种放大已取消，与 Word 导出原有的表现一致。
- 设置的默认值原本可能被修改操作连带改写，「恢复默认」因此无法完全复原，设置会逐渐偏离出厂状态。默认值现在每次独立构造，单项修改不再影响它。

## [3.15.0] - 2026-09-29

### 排版与水印

- 修复：水印的不透明度设置此前只作用于 PDF 导出，Word 导出按固定浅灰输出。现在两端都按所设的不透明度输出。
- 改进：水印默认角度由 45° 改为 315°，倾斜方向改为中文排版里惯用的左下至右上。
- 修复：导出 Word 并开启水印时，WPS 会在页面上标出一条与水印同向的红线，Word 中没有这个现象。这条线不在文档里，是 WPS 把水印文字当成正文做拼写校对的结果；水印属于装饰性内容，本不该参与校对，现已排除在校对范围外。

### 修复

- 页眉「默认」模式在两种导出下原本不一致：Word 导出在页眉放入文档标题，PDF 导出的页眉为空，标题只出现在浏览器标签页。现在两者都在页眉居中显示文档标题。
- 批量转换完成后，结果弹窗内的转换 / 批量 / 合并 / 追加文件 / 清空列表 / 选择文件六个按钮保持禁用，无法再次触发转换。关闭弹窗后按钮恢复可用。
- 成书向导中增删源文件后关闭向导时，按钮同样保持禁用。
- 设置抽屉「模板预设」下拉的展开箭头原本落在输入框之外，点击没有反应，输入框也偏窄，长预设名会被截断。箭头现在移回框内右端，输入框加宽到能完整显示预设名。
- 关闭「自动目录」后，其下的目录模式（静态 / Word 域）下拉仍然显示，选中的模式不会生效。重新打开「自动目录」会恢复上次的选择。成书向导的同一处也一起修了。
- 「题注编号」的说明文字原本写作「图 1-1」，实际产出的是「图 1.1」。三种语言的说明都已改为与产物一致，编号本身没有变。

### 界面

- 官网在手机与小窗宽度下，顶栏的章节编号会被静默裁掉：430~550px 之间「04 技术栈」整条消失，原因是品牌字标一直占着位置。这个区间现在也隐藏品牌字标，四个编号完整可见。

## [3.14.0] - 2026-09-27

### 转换与排版

- 新增：「AI 清理」清除 AI 输出里最常见的残留：裸数字引用标记（`[1]`、`【4】`）、全部 emoji（含 👨‍👩‍👧 这类组合、肤色、国旗、键帽），以及「直接从二级标题起手」造成的标题层级错位（自动上移一级并补齐跨级）。
- 脚注、链接、代码块与行内代码的内容不受影响，`©` `®` `™` `✓` `§` `→` 这类正文符号也保持原样。关闭「AI 清理」则完全不做这些改写。
- 新增：「AI 清理」下新增两个分档开关，「保守规整」只做不改变内容的规整（引号、破折号、列表标记后的空格、空行），「结构改写」负责删引用标记与 emoji、统一标题层级。
- 担心正文被动过时，可以只关掉「结构改写」，不必停用整个功能。总开关关闭时两个分档置灰，并有一行文字提示要先开启总开关。
- 新增：转换前检查新增四类「内容可能已被静默丢掉」的情况，包括 ChatGPT 常见的 `\(x\)` 公式定界符（只认 `$…$` 与 `$$…$$`，写错会按普通文字印出）、不在支持范围内的 HTML 块级标签（如 `<table>`，内容会整块丢弃）、未闭合的代码围栏或未配对的 `$`，以及形似表格却没排成表格的行。每一类都写明了后果与改法。

### 修复

- 转换前检查报告此前只针对单文件转换，批量转换、成书向导付印、剪贴板直转和最近记录里的「重新转换」都不弹报告。现在这五个入口都会弹出；一次转换多个文件时，报告按文件分组列出并标明是哪个文件。
- 合并转换时若某份文件有未闭合的代码围栏，它之后的内容（包括后续所有文件）会被静默并进同一个代码块，等于凭空少掉几份稿子。现在直接阻止合并，并说明是哪个文件第几行。
- 单文件与批量转换不受此限，仍是「警告 + 可继续」。
- 未闭合围栏的提示原本说之后的内容「不显示」，实际照样显示，只是变成一个代码块。措辞已经改准，并说明标题、表格、公式都会变成代码文本。
- 合并被阻止时的提示原本把同一段长文本显示两遍，两处都被裁掉，标题还写着「合并失败」，而实际合并并未开始。现在长文本只显示一次且完整可读，标题改为如实描述。

## [3.13.1] - 2026-09-26

### 修复

- 列表项和引用块里的公式原本原样显示成 LaTeX 源码，比如 `\frac{1}{2}` 带红线波浪。现在正常渲染为公式。
- 行间公式的上下限原本挤在符号右侧，`∑` 的上下标和 `lim` 的下方都在右边。现在按惯例排在上下方。
- 列表项里的公式原本按整个页面宽度居中，超出列表范围。现在对齐到列表内容栏。
- 引用块里原本只有部分内容带灰底（公式有，表格和代码块没有），灰底与引用块边界不齐。现在整块连成一片。

## [3.13.0] - 2026-09-26

### 转换与排版

- 修复：图题注与表题注使用同一个标签时会互相挤掉，导致表题注的交叉引用被误报「未找到」。现在图与表各有独立的标签空间。
- 改进：公式里引用外部链接或外部图片的指令（`\href`、`\includegraphics`）不再写进产物，只按源码显示。

### 界面与交互

- 转换完成时结果区播放一次收束动画，只给成功态。开启「减少动态效果」后不播放。
- 弹窗与设置抽屉关闭后，焦点回到打开它的那个控件。设置抽屉打开时焦点落在当前所在分组，而不是「关闭」按钮。
- 队列在转换期间明确置灰。此前各行仍可拖动重排、双击预览，但这些操作对本次转换无效。
- 关于窗口的版本号有了可见标签，此前只能靠悬停提示得知。版本、许可等元信息改为成对播报，链接下划线常驻显示，不再只靠颜色区分。

### 稳定性与数据安全

- 修复：双击「添加文件」会弹出两个文件选择窗口。现在任何入口（按钮、拖放区、继续添加、快捷键）在文件窗打开期间都只弹出一个，取消或出错后也能正常再开。
- 修复：付印按钮的脉冲动画会挡住按钮自身的投影，导致鼠标悬停时的抬升效果一直失效。
- 修复：队列行的悬停提示会字面显示 `${path}`，而不是文件名。
- 复制成功或失败现在会被读屏软件播报。此前复制反馈只是按钮内文字变化，不播报。
- 设置与最近文件改为写入后强制落盘。断电或掉电不再可能得到空的设置文件，偏好不会被静默重置。
- 补齐两处权限校验，此前只有一处。渲染进程一旦被攻破，可提升权限的路径更少。
- 只能打开本次会话真实生成过的产物文件，范围比此前更窄。
- Mermaid 图形渲染失败的原因不再只留在控制台，现在能在警告区看到。

### 安装与分发

- 修复：安装包此前按需要管理员权限的方式安装，在无交互环境下会安装失败，并在系统里留下一个无法卸载的残留条目。现在按当前用户模式安装，无需管理员权限。
- 安装包仍未做代码签名，首次运行时 Windows 可能提示未知发布者。未签名的风险与校验值随发布说明一并给出。
