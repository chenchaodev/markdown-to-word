# CHANGELOG

> 版本演进历史,面向终端用户。只记录你能感知的变化(新增 / 改进 / 修复 / 注意);内部重构、测试、构建与发版流程不在此列出。

## [3.10.1] - 2026-08-30

### 新增
- 剪贴板直转:不必先把 Markdown 另存为文件,主界面空态「选择文件」下方新增「粘贴 Markdown 转换」,直接读剪贴板文本转换;剪贴板是文件路径时复用拖入队列;空或非文本给出提示。
- 成书向导:七步引导式串联模板预设、页眉页脚、水印、合并、模板导入与封面页,向导内设置实时保存;全程无需打开设置面板即可产出复杂成书。
- 首次启动引导:首次启动出现「选预设 → 向导 → 转换」引导路径,可跳过、不强制打开设置面板;非首次启动不再出现。
- 预设覆盖扩面:内置预设现覆盖页眉页脚(标题居中+页码)、水印、公式编号、H1 前分页;切换预设时提示本次被覆盖的设置组。
- 向导补全高频项:成书向导内可直接设置边距、字体微调、标题档位、编号开关、输出目录、导出后行为、页眉 logo,与设置面板手动设置等价。

### 修复
- 向导第五步选了多个文件后「下一步」不再误判为不可用。
- 矮窗口下完成结果区不再出现多余滚动条;主窗口不再因结果区内容变多而上下跳动。
- 向导与弹窗对话框内容不再溢出、文件路径完整可见;提示不再被设置面板或弹窗遮罩遮挡。
