# archive/ 分析原文存档(面向开发者)

> 本目录存子代理研究/分析**完成的原文**,供开发者学习「为什么采用此结论」。
> 子代理/主会话不读、不登记、不加入 docs/ 索引;本目录只增不改,与主会话维护的 docs/ 根目录分开;清理归口开发者:条目数 >30 或每季度由开发者压缩/归档(主会话不负责清理)。

- **目录清单 → [`INDEX.md`](INDEX.md)**(生成式,不手工登记):一行一文件,给出工作项ID、主题与**分流去向**。**回捞路径 = 本表分流去向列 → 对应结论条目**。
- 本目录**不是容量泄压阀**:常驻文档超容量契约时**默认动作是条目级外迁**(整块原样搬进同层子目录的独立文件,主文件留一行索引),只有**整份文档生命周期结束**时才进本目录 —— 泄压过来等于制造不可达内容。
- 命名:`YYYYMMDD-HHmmss-<工作项ID>-主题.md`(禁冒号;文档条目内时间戳用 `YYYY-MM-DD HH:mm:ss`);**<工作项ID> 可省略**(无工作项上下文的存档留空,不要编造)
- 来源:全局 AGENTS.md「落盘格式」节
- 用途:结论摘要已在 [RESEARCH.md](../RESEARCH.md) 索引(条目正文在 `research/`)与 [ADR.md](../ADR.md) 索引(条目正文在 `adr/`),此处保留原始分析依据
