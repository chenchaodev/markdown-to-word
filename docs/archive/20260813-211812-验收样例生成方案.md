# 验收样例生成方案选型

- 时间: 2026-08-13 21:18:12
- 决策人: 用户拍板(方案对比后)
- 关联: RESEARCH.md 条目「验收样例生成方案选型」;测试基建试点提交

## 背景

- 痛点: `test/fixtures/` 仅 2 张 png + 陈旧的 `manual/`(手工维护的合并长文档,批次 3 前后制作,仅 merge.test.js 消费);27 个测试段的 md 样例全部内联在段内(`const MD = ...`),用户 GUI 人工实测时没有与最新功能对应的 md 文件,需要自己找/写。
- 历史线索: 早期曾有 `make-batch4-sample.mjs` 生成脚本(已删除),「生成式样例」有先例。

## 方案对比

| 方案 | 优点 | 缺点 |
| ---- | ---- | ---- |
| A 独立手写验收样例集 | 样例自然、可控制 | 手工维护成本;与自动化断言(测试段内联 md)存在漂移风险——两边改着改着不一致 |
| B 测试段导出 → 生成器落盘(拍板) | md 唯一事实来源 = 测试段;零重复、永不漂移、自动跟功能走;新增功能 = 段加导出,生成器零改动 | 测试段需小幅改造(每段 +2 行);验收 md 含刺探式内容(悬空/开关场景,人工实测本就需确认降级行为) |

- 关键洞察: 验收 md 的事实来源其实是测试段内联字符串,但没有机制落成文件——方案 B 只是把「导出 → 落盘」机械化。
- 另两个决策: 试点 4 段先行(cross-ref/eq-numbering/toc-caption/mermaid)验证后全量;触发方式 = 手动 npm script + 提交前 `--check`(不并入 test,纯 node 不必混入 build+electron 开销)。

## 机制(已落地,试点)

- 约定: 测试段顶层 `export const fixtures = { main: \`...\`, special: \`...\` }`;`main` → `acceptance/<段基名>.md`,其余 key → `<段基名>-<key>.md`;段基名 = 文件名去 `.test.js`。
- 生成器 `test/tools/gen-fixtures.mjs`(纯 Node): 扫描 segments/main 动态 import → 落盘;正则提取 md 内 `![...](path)` 与 `src="..."` 图片引用(排除 http/https/#锚点/data:),存在则复制到 acceptance/ 同相对路径,缺失静默跳过(缺失图片样例本就是演示缺失警告);生成 `acceptance/README.md` 索引(JSDoc 首行 + 对应测试段)。
- `--check` 模式: 内存重生成逐字节比对(含 README/图片),差异打印首处差异行 + exit 1;幂等。
- 命令: `npm run gen:fixtures`(需先 build)/ `npm run check:fixtures`。
- 边界: 无 fixtures 导出的段静默跳过(先正则探测再 import,避免 electron import 噪音);含 fixtures 段 import 失败一律 exit 1(防止产出不完整索引覆盖旧产物,Windows 反斜杠路径坑已修)。

## 踩坑(实测)

- `test/common/pdf-utils.js` 顶层 `import { BrowserWindow } from "electron"` 在纯 Node 下必抛 SyntaxError → 新增 electron mock 桥接(`test/tools/electron-mock-loader.mjs` + `electron-mock.mjs`,`node:module.register` 将 electron 解析为最小 mock;段模块顶层仅 import 声明、方法在 run() 内才调用,空实现足够)。
- 初版曾因 Windows 反斜杠路径未命中 `"dist/"` 判断而静默跳过并覆盖旧产物 → 修复为错误含 dist 路径时给 build 提示并 exit 1。

## 验证事实(2026-08-13)

- 生成: 扫描 30 段,4 段含导出,产出 6 md + 1 图片 + README;幂等(连跑 gen,check exit 0);dist 缺失 → 明确提示 + exit 1。
- `npm run test` 30/30 段全绿(4 段迁移零回归)。
- 落盘: cross-ref.md / eq-numbering.md / toc-caption.md / mermaid.md / mermaid-special.md / mermaid-js.md + g1-tiny.png + README.md。
