# 模板导入方案（批次 13 规划依据）

- 时间:2026-08-14 20:16:22
- 来源:@librarian lib-1(外部调研)+ @explorer exp-1(机制盘点)
- 关联:docs/RESEARCH.md 条目;验收 docs/ACCEPTANCE.md 批次 13

## 背景与需求

ROADMAP 功能候选「模板导入(中高;无依赖,先导出侧)——用户上传 docx/CSS 作为样式模板」。用户 2026-08-14 拍板实施。

## 本地现状（exp-1 机制地图要点）

- 预设 = 纯数值快照 `{name, typography, pageSetup}`;硬编码 3 项 TEMPLATE_PRESETS(默认/学术论文/商务简报,注释「预设值已定稿,勿改」)+ 自定义 customPresets(上限 10,去重保留先出现,截断)
- 渲染管线只认最终字段值(typography/pageSetup),预设无独立概念;docx 走 styles.default(字体/字号)+ 段落(行距/缩进/对齐)+ numbering + section(纸张/边距);pdf 走 buildTemplateCss 模板字符串参数化
- pdf CSS 全部集中在 src/core/pdf/template.ts(单一模板字符串,无 CSS 变量机制,类名固定)
- 校验链路完备:main/settings.ts sanitizeCustomPresets(逐条)/sanitizeTypography(钳制)/sanitizePageSetup(0-1000mm)——JSON 导入只需复用
- 测试契约:presets.test.js(3 预设/值域/matchesPreset 14 字段全等)、settings.test.js(customPresets 校验面)、settings-logic.test.js(validatePresetName 文案含全角逗号)

## 五方案对比（lib-1）

| 方案 | 依赖 | 可行性 | 成本/风险 | 价值 |
|---|---|---|---|---|
| 1. docx 模板导入 | docx4js 3.3.0(单人维护,2024-09 停更) | 低:OOXML 样式→参数模型逆映射工程量大 | 高/高 | 中 |
| 2. CSS 模板覆盖(pdf) | 无 | 高:buildTemplateCss 后追加 <style> 覆盖 | 低-中/低 | 中 |
| 3. 预设 JSON 导入/导出 | 无(复用 sanitize) | 极高:数据契约就是 CustomPreset[] | 低/低 | 中-高 |
| 4. pandoc reference.docx | 借鉴不引入 | 仅设计参照 | — | — |
| 5. 导出优先 | 无 | 极高 | 低/低 | 高 |

## 决策

- **批次 13 = 预设 JSON 导入/导出(方案 3+5)**:数据契约即 CustomPreset[],导入=读文件→sanitizeCustomPresets→追加合并(同名覆盖)→上限 10 截断;导出=JSON.stringify + 保存对话框
- **CSS 模板覆盖(pdf 路线)次选**:buildTemplate 的 <style> 后追加用户 CSS(后加载天然覆盖);需防用户 CSS 破坏 .page-break/breakBeforeH1 分页强制规则(建议用户样式限定配色/字体类);docx 路线不做 CSS(OOXML 不消费 CSS)
- **docx 模板导入暂缓记 ROADMAP**:docx 9.x 仅 patchDocument 占位符替换(不提取样式);docx4js 单人维护 + 3.x 破坏性变更 + 需自写 visitor 提取 OOXML 样式映射到参数模型(把 docx 样式语义完整实现一遍,与自研渲染管线架构相悖);.dotx 与 .docx 同容器无捷径;若未来做受限版(只支持预定义样式名清单)可照 pandoc reference.docx 范式设计

## 功能规格（批次 13）

- **JSON 格式**:`{ "schemaVersion": 1, "presets": [{ name, typography, pageSetup }] }`;兼容裸数组(归一化后过 sanitize)
- **导出**:模板预设行「导出预设…」按钮 → main 保存对话框 → 导出全部 customPresets;无自定义预设时提示
- **导入**:「导入预设…」按钮 → main 打开对话框 → 读文件 → parse + schemaVersion 检查 → sanitizeCustomPresets → 追加合并(同名覆盖)→ 上限 10 截断 → 返回 {ok, imported, overridden, error};renderer 反馈 + rebuildPresetOptions
- **IPC**(preload 白名单):`importPresets()` / `exportPresets()`(main 内 dialog + fs + sanitize 全包)
- **测试**:mergePresets 纯函数直测(同名覆盖/上限截断/非法条目丢弃/裸数组兼容/schemaVersion 校验);文件对话框走 GUI 实测
