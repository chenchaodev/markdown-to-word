# docx 页眉页脚 + 页码调研报告

- 调研时间:2026-08-05
- 调研代理:@librarian(lib-3)
- 结论先行:方案明确、风险低。页眉页脚只能挂 section(9.x),页码字段 PageNumber 用法两代一致;唯一易踩坑是 `PageNumberFormat`(旧)→ `NumberFormat`(9.x 新)。

## 一、核心结论

1. **Header/Footer 构造**:`new Header({ children: (Paragraph|Table)[] })`,children 只收段落/表格,**不能放裸 TextRun**;页码字段必须包在 Paragraph 里
2. **挂载点**:只有 `sections[].headers/footers`(Document 级无此选项);单节文档直接加到现有唯一 section
3. **首页不同**:section `properties.titlePage: true` + `headers.first`/`footers.first`
4. **PageNumber 是常量对象**:`{ CURRENT, TOTAL_PAGES, TOTAL_PAGES_IN_SECTION, CURRENT_SECTION }`,放 `TextRun({ children: [...] })` 内;源码按字符串 switch 生成域:`CURRENT`→PAGE,`TOTAL_PAGES`→NUMPAGES
5. **中文模板「第 X 页 / 共 X 页」完全支持**:字段与普通文本任意混排;两种写法等价(多 TextRun 拼 / 单 TextRun children 混合数组,非 PageNumber 字符串自动按普通文本处理)
6. **页码格式坑**:9.x 无 `PageNumberFormat`(旧版,已改名)!正确写法是 section `properties.page.pageNumbers: { start?, formatType?: NumberFormat, separator? }`;`NumberFormat` 枚举含中文格式(CHINESE_COUNTING 等);**建议保持默认 decimal**——与 PDF 侧阿拉伯数字对齐,中文数字在 WPS/LibreOffice 渲染不如 decimal 稳
7. **合并场景**:项目合并 = 文本拼接后单次渲染单 section → 页眉页脚自动覆盖所有页、页码天然连续;TOTAL_PAGES 统计全文档(含封面/目录),与 PDF footerTemplate 的 totalPages 语义一致,两边对齐
8. **封面页码**:titlePage + 空 first footer 会让 pdf/docx 分叉(printToPDF footerTemplate 无法按页排除),建议保持所有页显示,与 PDF 对齐
9. **可选增强**:`features: { updateFields: true }` 强制打开即刷新全部域(与 TOC 域同机制),非必需

## 二、最小样板(9.7.1 可用)

```ts
import { AlignmentType, Document, Footer, Header, PageNumber, Paragraph, TextRun } from "docx";

function renderHeader(title: string): Header {
  return new Header({
    children: [
      new Paragraph({
        alignment: AlignmentType.CENTER,
        children: [new TextRun({ text: title, size: 14, color: "888888" })],
      }),
    ],
  });
}

function renderFooter(): Footer {
  return new Footer({
    children: [
      new Paragraph({
        alignment: AlignmentType.CENTER,
        children: [
          new TextRun({ text: "第 ", size: 14, color: "888888" }),
          new TextRun({ size: 14, color: "888888", children: [PageNumber.CURRENT] }),
          new TextRun({ text: " 页 / 共 ", size: 14, color: "888888" }),
          new TextRun({ size: 14, color: "888888", children: [PageNumber.TOTAL_PAGES] }),
          new TextRun({ text: " 页", size: 14, color: "888888" }),
        ],
      }),
    ],
  });
}

const doc = new Document({
  styles: { /* 现有 */ },
  numbering: numberingOptions(),
  sections: [
    {
      properties: { page: { size, margin } },
      headers: title ? { default: renderHeader(title) } : undefined,
      footers: { default: renderFooter() },
      children,
    },
  ],
});
```

注:`size` 单位是半磅(PDF 9px ≈ 6.75pt,取 14 = 7pt 视觉接近);颜色 6 位 hex 无 `#`。

## 三、落地改动点清单(编排器用)

1. `src/core/docx/render.ts`:`RenderOptions` 增 `title?: string`;renderDocx 内构造 Header/Footer 挂到现有 section;页眉标题 = `options.metadata?.title ?? options.title`
2. `src/core/convert.ts`:docx 分支补传 `title: context.title`(与 pdf 分支一致)
3. 验证:typecheck + 生成 docx 在 Word/WPS 打开确认页码显示(字段机制与现有 TOC 相同)
