## 战略背景（一句话）

3.6.0 已把「正式交付」能力链做全，基础转换 + Mermaid + 公式 OMML 已成及格线、不再是卖点。护城河 = 离线隐私 + 中文保真 + 易用 GUI；AIDOC Station / Marksmith 等新竞品已在红海能力上逼近，下一步应从「堆能力」转向「体验差异 + 填补空白点」。竞品普遍短板 = 中文排版错乱、目录页码不专业、AI 输出粘贴即崩、批量/合并成书缺失、在线工具隐私硬伤。

## 评分约定

| 维度 | 范围 | 含义 |
|---|---|---|
| 业务价值 | 1-100 | 越高对用户/市场价值越大（纯价值评估） |
| 成本 | 1-100 | 越高 = 实施投入越大（人力 / 工期 / 风险 / 新依赖） |
| 综合优先级 | 1-100 | 越高越建议优先推进（综合业务价值、成本与战略契合；战略冲突作为真实成本计入，非历史偏见） |

> 排序依据：综合优先级降序。历史状态列标注该项是否曾「砍」及本次重审判断。

## 推荐 Top 5（供参考，非强制）

1. **B1 AI 清理前置** — 成本最小、直击最大新痛点、不碰隐私红线
2. **A1 开箱中文预设包** — 最直接巩固护城河，工作量中风险低
3. **B4 成书向导** — 把已交付能力转化为用户可感知的「成书」体验，GUI 竞品真空
4. **B2 高保真预览** — 旗舰特性，排期靠后但战略价值高
5. **C1 笔记联动（Obsidian）** — 趋势标配，离线区隔云端方案

## 明确不建议做（避免资源分散）

- 基础转换重投、Mermaid 图片/公式 OMML 重投、通用在线转换器（红海/与卖点冲突）
- PDF 多栏 / 批量重命名 / 目录监视同步 / 代码高亮主题切换 / 完整 CSL（ROI 低或需求弱，维持砍）
- AI 改写（云 LLM）、自动更新（维持砍；签名可单拆）
- **双管线合并**（架构已定「契约共享 + 测试锁定」为正确代价，勿动）

## 关键提醒

- **AI 清理 ≠ AI 改写**：B1 规则化离线必做；AIW 生成式破隐私不做。竞品趋势里的「AI→Word 清理器」指前者。
- **加密（C4）值得单独立项评估**：不是功能堆砌，是把「离线隐私」变可验证能力；若排期建议 PDF 先行、docx 次之，并计入 qpdf 原生二进制镜像分发成本。
