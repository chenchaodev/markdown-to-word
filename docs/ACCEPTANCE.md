## 待实测清单

### S1 列表增删
- [ ] 单文件态「移除」按钮:点击后回到初始态
- [ ] 多文件态「追加文件」:对话框追加,重复文件不重复入列(状态区提示跳过)
- [ ] 多文件每项「✕」移除按钮:单项移除,剩余序号重排
- [ ] 「清空列表」按钮:全部清空回到初始态
- [ ] 拖入新文件 = 追加(不替换现有列表)

### S2 输出目录
- [ ] 设置面板「输出目录」:显示当前值(默认「源文件所在目录」)
- [ ] 「选择…」选目录后转换产物落到该目录;目录不存在时自动创建
- [ ] 「恢复默认」回到源文件同目录
- [ ] 重名测试:同一文件连续转换两次 → 第二次产物为「名 (2).docx/pdf」,不覆盖

### S3 进度与取消
- [ ] 转换中显示进度条 + 百分比 + 取消按钮(**合并进度条 bug 已修复 524cdf2,待复测:合并转 PDF 看 15%→70%→95% 递进**)
- [ ] 单文件/批量/合并均可取消;取消后状态区与汇总条显示「已取消」(**取消后重试秒失败已修复 fd40480;PDF 取消不生效已修复 f809c57,待复测**)
- [ ] 批量取消:未开始项记「已取消,未转换」,成功项产物保留
- [ ] PDF 取消说明:printToPDF 为 Electron 原子调用,点取消后需等当前轮打印结束才中止(大文档数秒延迟),最终不产出文件、显示「已取消」

### 失败/警告可见性
- [ ] 单文件失败:弹窗标题「转换失败」+ 文件名 + 红色原因(错误三要素)
- [ ] 汇总条常驻:完成后显示完成路径 + 「打开所在文件夹 / 打开文件」按钮
- [ ] 警告(缺失图片等)折叠在汇总条「警告(N)」内
- [ ] 批量失败后「失败详情」按钮重开逐条弹窗

### 编码与非法输入
- [ ] GBK 编码的 md 文件可直接转换(状态区/警告提示「已按 GBK 编码读取」)
- [ ] 边距输入非法(如 9999)字段内提示并恢复原值
- [ ] 字号/行距超范围、字体为空:字段内提示
- [ ] 模板微调后下拉回退「默认」并提示「已微调,与模板预设不一致」

### 操作与文案
- [ ] Ctrl+Enter 触发主转换(单文件/批量);Ctrl+O 添加文件
- [ ] 完成弹窗「复制路径」按钮可复制
- [ ] 批量完成后仅首个成功项按「导出后」设置自动打开(不会弹 N 个)
