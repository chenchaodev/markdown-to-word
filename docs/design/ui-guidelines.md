# MarkdownToWord · 界面设计规范速查（印刷付梓）

> 适用：renderer 层所有新增 / 修改的界面元素。视觉基准样稿：`docs/design/ui-mockup.html`。
>
> **单一来源声明**：本节 token 实现时落为 renderer CSS 变量（`:root` 与 `html[data-theme="dark"]` 两套取值），
> 任何样式不得绕开 token 硬编码 hex / px——与 `core/docx/theme.ts` 集中字体配置同一纪律。

### 1.2 字体栈（三套，角色固定不混用）

| 角色 | 栈 | 用于 |
|---|---|---|
| 展示 serif | `"Source Han Serif SC","Noto Serif SC","Songti SC",SimSun,serif` | 空态大标题、抽屉章节题、弹窗题字、品牌钤印；**只做声音，不做正文** |
| 界面 UI | `"Microsoft YaHei UI","Microsoft YaHei","PingFang SC","Segoe UI",system-ui,sans-serif` | 全部正文、控件文字、列表 |
| 数据 mono | `"Cascadia Code","JetBrains Mono",Consolas,monospace` | 路径、数值（pt / 倍数 / mm）、时间、百分比、快捷键、PDF CSS |

### 1.3 形状 · 间距 · 阴影

- 圆角档：窗口 12 / 卡片·抽屉 10 / 按钮 8（sm 7）/ 输入件 7 / 胶囊徽章 999 / 文稿台 3（签名元素特例）
- 控件高：输入件与标准按钮 32–34、sm 29、主按钮 40；间距 8px 基准，区块之间 24
- 阴影两档：`--shadow-card`（静置卡片）、`--shadow-pop`（浮层）；红色主按钮专属 `--acc-ring` 投影
- 分区靠 1px 发丝线（`--line`），禁止粗分割条、大色块分区

## 2. 控件模式清单

| 模式 | 适用场景 | 交互要点 |
|---|---|---|
| 分段切换 seg | 枚举 ≤5 且互斥 | 选中 = 纸面浮起 + 加粗；即时生效类（主题 / 方向）点击即应用 |
| 下拉 sel | 枚举 >5 | 原生 select + 自绘箭头；focus 朱砂描边 + 浅环 |
| 步进 stepper | 有界离散数值（正文字号 pt） | ±0.5 步进；值居中等宽字体；上下限钳制 |
| 滑杆 range | 有界连续数值（行距倍数） | 右侧等宽实时回显，不弹气泡 |
| 开关 switch | 布尔偏好 | 含义不自明的配一行灰色说明（如「首行缩进——正文段落首行缩进 2 字符」） |
| 折叠分组 acc | 低频高级项 | 默认收起；头部右侧给内容概览（「边距 · 编号 · 模板管理」） |
| 文件卡 filecard | 单文件态 | 图标块 + 文件名 + mono 元信息 + 能力 chips + 动作组（追加 / 预览 / 移除） |
| 队列行 mlist li | 多文件态 | grip 拖拽排序、序号自动重排、行内移除；底部固定批量 / 合并语义说明 |
| 最近行 rrow | 空态一键重转 | 默认安静，hover 才浮现「重新转换 / 打开所在文件夹」 |
| 结果汇总条 res-row | 转换完成 | 绿勾徽 + mono 路径截断 + 「打开所在文件夹 / 打开文件」右对齐 |
| 进度条 progress | 转换进行中 | 5px 细轨 + mono 百分比 + 「取消」常驻；状态行圆点同色呼吸 |
| 弹窗 modal | 完成确认等阻断反馈 | 钤印动画仅播一次；路径可复制（✓ 反馈）；Esc / 点遮罩可关 |
| 设置抽屉 drawer | 设置集合 | 右滑覆盖 + 遮罩；七组编号（01–07）；底部「恢复默认 / 完成」 |
| toast 轻提示 | 即时操作反馈（切换预设列出被覆盖组、复制成功等） | 动作栏上方居中浮入；2.4s 自动消失，可被下一条顶替；单实例；只陈述事实，不致歉不营销 |
| 常驻可折叠区 | 主舞台与消息区之间的低频附属列表（最近转换） | 40px 标题条常驻；空态默认展开、有文件默认收起；无记录整块不渲染；列表内部滚动约 3 行 |

## 3. 扩展规则

### 3.1 新配置项 → 控件映射（强制，禁止发明新控件形态）

| 数据类型 | 落位 |
|---|---|
| 布尔 | switch |
| 枚举 ≤5 | seg 分段 |
| 枚举 >5 | sel 下拉 |
| 有界数值（离散） | stepper |
| 有界数值（连续） | range 滑杆 |
| 路径 | path-chip + 「更改…」按钮 |
| 文本（有限建议集，如字体名） | combo：`input` + `datalist` |
| 多字段数值组（四边边距） | 带单位输入件网格（不用滑杆） |

确需新模式：先改本文档并说明理由，确认后再实现。
「模式 + 条件字段」是抽屉唯一折叠形态：主控分段（含关闭档）置首，条件字段收入凹陷容器（`--inset` 底 + 左侧轨），未启用整块移除而非灰禁。实例：页眉模式；未来水印、目录增强复用同一容器。

### 3.2 新设置项层级判据（抽屉七组，已按 settings-ia.md 确认）

| 组 | 收录判据 | 入预设 |
|---|---|---|
| 01 预设 | 风格起点与其管理 | 本体 |
| 02 页面 | 物理版面（纸 / 向 / 边距） | ✅ |
| 03 文字 | 字符与段落观感 | ✅ |
| 04 页眉 · 页脚 | 页面附加身份信息 | ❌（组头徽标） |
| 05 编号与目录 | 结构惯例 | ✅ |
| 06 输出 | 产物去向与处置 | ❌ |
| 07 应用 | 软件自身偏好 | ❌ |

- footerEnabled＝「自定义页脚」，仅自定义模式生效；默认模式的固定页码页脚不受开关控制。
- 预设切换用 toast 列出被覆盖的组（页面 · 文字 · 编号与目录）。
- 预留落位：F5 水印 → 04 第二区块；F6 预检 → 06；F7 目录增强 → 05 toc 条件子行；F8 合并总目录 → 05 尾（「仅合并」角标）；F9 docx 模板导入 → 01 管理行。
- 非设置类新功能区块：先问「是否服务当前这一次转换」——是 → 主舞台 / 消息区 / 动作栏；否 → 进抽屉对应层，不得放上主界面。

## 4. 关键取舍（红线重申）

1. **红色语义纪律**：朱砂红仅限「付印」动作——转换主按钮、选中态描边、钤印、进行中状态。破坏性操作（移除 / 取消 / 清空）用墨色描边或幽灵按钮，**不用红**。
2. **衬线只做声音不做正文**：serif 仅用于标题、章节编号、题字；正文与控件一律 UI 栈。
3. **装饰预算集中制**：签名元素只在空态文稿台一处（裁切线 + 直排 + 钤印）；新增界面不得自带插画、大色块、新动效；hover 微交互 ≤150ms，transition ≤260ms，且必须兼容 `prefers-reduced-motion`。
4. **密度秩序**：数字 / 路径 / 时间 / 快捷键一律 mono；信息分层靠字重与三级文字色，不靠加框堆线。
5. **浮层不出窗**：抽屉与弹窗都约束在窗口框内；遮罩抽屉盖内容区、弹窗盖全窗。

## 5. 流体布局档位（实现参照）

断点跟随**窗口宽度**（Electron 内即 viewport），实现用 CSS 变量 + 两档 media/container query：

| 档位 | 触发 | 行为摘要 |
|---|---|---|
| 舒适 | 窗宽 >1080px | 基准布局 |
| 紧凑 | ≤1080px | 四周留白收紧；抽屉 372px；主按钮收窄 |
| 窄窗 | ≤900px | 隐藏快捷键提示；单文件卡动作换行到卡底；结果路径独占一行；抽屉 `min(402px,100%)`；空态文稿压缩 |
| 矮窗 | 视口高 ≤640px | 标题栏降为 40px（抽屉 / 遮罩 top 联动 `--tbh`）；空态纵向压缩；消息区 / 动作栏降高 |

BrowserWindow 建议钳制：`minWidth: 880`、`minHeight: 560`；CSS 在 ~820px 以下仍可用，低于此不承诺。

高度预算：空态投放区已压缩垂直空间（drop-core 42/56/36、节奏 11px），最小窗高 620 时「舞台＋折叠历史条＋消息区＋动作栏」免滚动完整可见；历史展开后列表内部滚动（约 3 行，矮窗档 2 行），不撑高窗口。
