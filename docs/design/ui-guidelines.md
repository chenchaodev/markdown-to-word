- 圆角档：窗口 12 / 卡片·抽屉 10 / 按钮 8（sm 7）/ 输入件 7 / 胶囊徽章 999 / 文稿台 3（签名元素特例，v4r2 起即常驻纸面容器圆角）

## 2. 控件模式清单

| 模式 | 适用场景 | 交互要点 |
|---|---|---|
| 常驻文稿台纸面 stage-paper | 主舞台容器（UI 改版 v4r2 ①） | `.stage` 即一张恒在的纸（纸面底 / 边线 / 3px 圆角 / 阴影）：空态呈现签名装饰与投放内容，文件态呈现队列，底部为快速参数脚注区——**三态同纸，切换只换内容，容器永不消失**；hover 仅边线加深，纸面不抬升 |
| 分段切换 seg | 枚举 ≤5 且互斥 | 选中 = 纸面浮起 + 加粗；即时生效类（主题 / 方向）点击即应用 |

| 步进 stepper | 有界离散数值（正文字号 pt） | ±0.5 步进；值居中等宽字体；上下限钳制 |
| 滑杆 range | 有界连续数值（行距倍数） | 右侧等宽实时回显，不弹气泡 |
| 开关 switch | 布尔偏好 | 含义不自明的配一行灰色说明（如「首行缩进——正文段落首行缩进 2 字符」） |
| 折叠分组 acc | 低频高级项 | 默认收起；头部右侧给内容概览（「边距 · 编号 · 模板管理」） |
| 文件队列卡 queuecard | 单文件与多文件统一形态（v4 ②） | 头部「文 稿」+ 计数 + 动作组（预览[仅 n=1] / 追加 / 清空）；队列行**直接排在纸面上**（发丝线分行，无嵌套卡壳；grip 拖拽排序 + 序号自动重排 + 行内移除，n=1 省略 grip/序号且列形收敛 `1fr auto`）；批量/合并语义脚注 = 纸面凹陷条，仅 n≥2 显示 |
| 最近浮出面板 pop-panel | 空态一键重转（v4 ④） | 标题条 40px 常驻占位、安静；展开体 absolute 浮层向上盖住舞台下部——**不挤压任何元素**；初始一律收起（浮层语义下默认展开即默认遮挡），仅 空→有文件 跃迁自动收起一次，外点自动收起；无记录整块不渲染；列表内部滚动约 3 行 |
| 快速参数条 quick-bar | 高频转换参数主界面直达（v4 ③） | **纸面底部脚注区**（发丝线分隔、无自绘底）：预设 sel + 纸张 seg + 方向 seg(纯图标) + 输出目录 chip + 更改…；与抽屉同源双向同步（paper/orientation 同名 radio 自动成组，select/chip 由 bindings 显式镜像）；抽屉仍为完整真相源 |
| 结果汇总条 res-row | 转换完成 | 绿勾徽 + mono 路径截断 + 「打开所在文件夹 / 打开文件」右对齐 |

## 3. 扩展规则

### 3.1 新配置项 → 控件映射（强制，禁止发明新控件形态）

| 数据类型 | 落位 |
|---|---|
| 布尔 | switch |
| 枚举 ≤5 | seg 分段 |
| 枚举 >5 | sel 下拉 |
| 有界数值（离散） | stepper |
| 有界数值（连续） | range 滑杆 |
| 路径 | path-chip + 「更改…」按钮 |
| 文本（有限建议集，如字体名） | combo：`input` + `datalist` |
| 多字段数值组（四边边距） | 带单位输入件网格（不用滑杆） |

确需新模式：先改本文档并说明理由，确认后再实现。
「模式 + 条件字段」是抽屉唯一折叠形态：主控分段（含关闭档）置首，条件字段收入凹陷容器（`--inset` 底 + 左侧轨），未启用整块移除而非灰禁。实例：页眉模式；未来水印、目录增强复用同一容器。

### 3.2 新设置项层级判据（抽屉七组 + 主界面快速参数条）

| 组 | 收录判据 | 入预设 | 上快速参数条 |
|---|---|---|---|
| 01 预设 | 风格起点与其管理 | 本体 | ✅ 仅切换（管理动作留抽屉） |
| 02 页面 | 物理版面（纸 / 向 / 边距） | ✅ | ✅ 纸张 + 方向（边距留抽屉） |
| 03 文字 | 字符与段落观感 | ✅ | ❌ |
| 04 页眉 · 页脚 | 页面附加身份信息 | ❌（组头徽标） | ❌ |
| 05 编号与目录 | 结构惯例 | ✅ | ❌ |
| 06 输出 | 产物去向与处置 | ❌ | ✅ 仅输出目录（导出后行为 / PDF CSS 留抽屉） |
| 07 应用 | 软件自身偏好 | ❌ | ❌ |

- 上快速参数条判据（v4 拍板）：**每次转换都会关心或经常调整**的项才上主界面；上移项在抽屉原位置保留——抽屉是唯一完整真相源，主界面只是高频镜像，两处同源即时同步。
- footerEnabled＝「自定义页脚」，仅自定义模式生效；默认模式的固定页码页脚不受开关控制。
- 预设切换用 toast 列出被覆盖的组（页面 · 文字 · 编号与目录）。
- 预留落位：F5 水印 → 04 第二区块；F6 预检 → 06；F7 目录增强 → 05 toc 条件子行；F8 合并总目录 → 05 尾（「仅合并」角标）；F9 docx 模板导入 → 01 管理行。
- 非设置类新功能区块：先问「是否服务当前这一次转换」——是 → 主舞台 / 消息区 / 动作栏；否 → 进抽屉对应层，不得放上主界面。

## 4. 关键取舍（红线重申）

1. **红色语义纪律**：朱砂红仅限「付印」动作——转换主按钮、选中态描边、钤印、进行中状态。破坏性操作（移除 / 取消 / 清空）用墨色描边或幽灵按钮，**不用红**。
2. **衬线只做声音不做正文**：serif 仅用于标题、章节编号、题字；正文与控件一律 UI 栈。
3. **装饰预算集中制**：签名元素（裁切线 + 直排 + 钤印）只在空态纸面一处，常驻容器本身保持中性；新增界面不得自带插画、大色块、新动效；hover 微交互 ≤150ms，transition ≤260ms，且必须兼容 `prefers-reduced-motion`。
4. **密度秩序**：数字 / 路径 / 时间 / 快捷键一律 mono；信息分层靠字重与三级文字色，不靠加框堆线。
5. **浮层不出窗**：抽屉与弹窗都约束在窗口框内；遮罩抽屉盖内容区、弹窗盖全窗；历史浮出面板盖舞台下部、不出内容区。

## 5. 布局契约与流体档位（实现参照；v4r2 重写）

### 5.1 统一内容列（全界面贯穿，红线级）

- `--col-w: 760px`：舞台纸面、历史标题条内容、消息区内容、动作栏内容**全部对齐同一列**——`padding-inline: max(原内边距, (100% − var(--col-w)) / 2)`；背景色带与发丝线仍全宽。
- 效果：标题栏以下，内容左右缘一条线贯穿到底，无宽度突变（v4 用户反馈「从上到下整体感」的落地）。

### 5.2 常驻文稿台 · 几何契约（红线级）

- `.stage` = 常驻纸面容器（§2 stage-paper），高度 `min(100%, calc(var(--panes-h) + var(--quickbar-h)))`：大窗取设计高（默认 320+42 / 矮窗 284+36，基准 = 空态文稿台自然高度），小窗填满弹性区——**任何窗口尺寸下参数脚注区都在视野内、页面零滚动**。
- 高度**只随窗口尺寸变化**，三种舞台状态（无文件 / 单文件 / 多文件）恒同高；历史开合（浮层不占布局）、消息增减、进度条出现均不改写纸面一个像素。
- 队列超长走 `.mlist` 内部滚动（listcard 弹性收缩，flex-fill 链路 `min-height:0` 不可断）。
- **消息区固定槽**：高 96px（矮窗 86）恒定，不随状态行/汇总条内容长高——转换开始与完成舞台零跳动；超长内容内部滚动，`justify-content: safe center` 防居中溢出裁顶（v4r2r2）。
- **进度行与按钮同行**：转换中隐藏快捷键提示（`:has(#progressArea:not(.hidden))`），动作栏恒高（v4r2r2）。
- 舞台高度 `min(100%, 设计高)` 本身保证页面级零滚动——**禁用 `scrollbar-gutter`**（单侧沟槽会把居中列顶偏，v4r2r1 踩坑）。
- 四角裁切线挂 `.stage` 容器角（`.stage` 直接子元素，仅空态显示），与脚注区实际高度解耦——挂在内容层用令牌反推，参数条折行时错位（v4r2r1 踩坑）。
- **级联纪律**：舞台域（.stage/.pane/.drop-core/.caps/.quick-bar/.qb-*）的响应式覆盖一律住 `drop.css §7`——base.css 先加载，覆盖留 base 会被 drop 同名规则按序压掉（v4r2 踩坑）。

### 5.3 断点档位

| 档位 | 触发 | 行为摘要 |
|---|---|---|
| 舒适 | 窗宽 >1080px | 基准布局 |
| 紧凑 | ≤1080px | 舞台四周留白收紧；抽屉 372px；主按钮收窄；输出目录 chip 收敛 200px |
| 窄窗 | ≤900px | 隐藏快捷键提示；结果路径独占一行；抽屉 `min(402px,100%)`；chip 收敛 170px |
| 半屏 | ≤720px | **参数条折两行**（行1 预设+纸张+方向，行2 输出目录整行，`flex:0 0 100%` 禁收缩）；空态能力胶囊让位；minWidth 640 起 |
| 矮窗 | 视口高 ≤640px | 标题栏降 40px；空态纵向压缩；消息区 / 动作栏降高；舞台设计高降档（284+36）。**高 DPI（125–150%）下日常即此档，按主体验校准** |

BrowserWindow：`minWidth: 640`（v4r2 自 880 下调，支持 1280/1366 屏半屏）、`minHeight: 560`；CSS 在 ~600px 以下不承诺。

### 5.4 视觉验证

界面改动交付前必须过 `npm run ui:shots`（Electron 截图 6 状态 + DOM 探针，产物 `output/artifacts/ui-v4/`）：空态 / 单文件 / 多文件 / 历史展开 / 880×620 压力位 / 640×560 半屏。工具已内置：初始化就绪轮询、状态迁移轮询、动效冻结（隐藏窗口 transition 时钟不推进，浮层 opacity 会冻在中间帧）。
