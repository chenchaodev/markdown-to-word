# 设置项信息架构重排规划（settings-ia）

> 状态：**已确认**（2026-08-25 五项开放问题全部拍板，另追加两项界面决策，见 §6）。样稿与规范已按本表同步。
> 输入：F4 页眉页脚功能加入后的完整设置契约；方法：按用户转换文档时的真实决策顺序重组，不受现有四层约束。

## 1. 新分组骨架总览

组序 = 决策序：**风格起点 → 物理页面 → 文字 → 页面附件 → 结构惯例 → 产出处置 → 软件偏好**。

| 组 | 组名 | 回答的心智问题 | 项数 | 入预设 |
|---|---|---|---|---|
| 01 | 预设 | 从哪个风格开始？ | 2 区块 | 是（本体） |
| 02 | 页面 | 纸多大、朝向边距如何？ | 3 | ✅ |
| 03 | 文字 | 字长什么样、段落怎么排？ | 8 | ✅ |
| 04 | 页眉 · 页脚 | 页面上附加什么身份信息？ | 5 | ❌ 徽标标注 |
| 05 | 编号与目录 | 结构惯例怎么定？ | 5 | ✅ |
| 06 | 输出 | 产物去哪、之后做什么？ | 3 | ❌ |
| 07 | 应用 | 软件本身什么偏好？ | 2 | ❌ |

顶栏 `format`（Word/PDF）不动；批量/合并动作留在底部动作栏，均不入抽屉。

## 2. 各组明细与组内排序理由

### 01 预设
1. **预设卡**（内置 3 + 自定义 ≤10，追加在后）——最高杠杆的单次选择，置顶；卡片下方加一行作用域说明：「预设包含 页面 · 文字 · 编号与目录；不含页眉页脚与输出」。
2. **管理动作行**：另存为预设 / 导入预设 / 导出预设 / 导入 Word 模板（F9 预留）——低频操作降级为次级行。

### 02 页面
1. **纸张** paper（seg×5）——最大的物理承诺，先定。
2. **方向** orientation（seg×2）——依赖纸张语境，紧随其后且必须在边距之上（横向时边距视觉含义翻转）。
3. **四边边距** margin×4（四格输入 + mm 后缀，0–1000）——微调项收尾；多字段数值组保持输入件形态，不用滑杆。

### 03 文字
1. **中文字体** fontEastAsia（combo）——中文用户第一观感，提到西文之前。
2. **西文字体** fontAscii（combo）——与中文成对渲染（eastAsia/ascii），相邻放置。
3. **正文字号** bodySizePt（stepper 8–24pt，±0.5）。
4. **行距倍数** lineSpacing（range 1.0–2.5）。
5. **标题字号档位** headingScale（seg：紧凑/标准/舒展）。
6. **标题间距档位** headingSpacing（seg：同三档）——与 5 同族相邻，命名对称。
7. **首行缩进** firstLineIndent（switch + 说明）——段落小节开始。
8. **对齐方式** align（seg：左对齐/两端对齐）——由布尔升级为枚举，与缩进构成「段落」小节。

### 04 页眉 · 页脚（组头挂「不入预设」徽标）
1. **页眉模式** headerMode（seg：默认/自定义/无）——总闸置顶。默认 = 文档标题居中 + 页码页脚。
2. **条件字段组**（仅自定义时展开，见 §4.1）：页眉文字 headerText（文本）→ 页眉图片 headerLogoPath（path-chip + 「选择图片…」IPC）→ 页眉布局 headerLayout（seg：居中/左右分栏）。排序依据：先内容后排布，文字使用频率高于图片。
3. **自定义页脚** footerEnabled（switch + 说明「显示“第 X 页 / 共 Y 页”；仅自定义模式生效」）——置于条件块内，仅自定义模式显示；默认模式的固定页码页脚不受任何开关控制。

### 05 编号与目录
1. **章节编号** headingNumbering → 2. **题注编号** captionNumbering → 3. **公式编号** equationNumbering——按文档元素层级 大→小 排列，三兄弟不拆散。
4. **自动目录** toc（switch）——目录展示编号结果，逻辑上在后。
5. **H1 前分页** breakBeforeH1（switch）——最粗粒度的结构效果，收尾。

### 06 输出
1. **输出目录** outputDir（path-chip + 更改…；说明「留空则保存到源文件所在目录」）。
2. **导出后行为** afterConvert（seg：无操作/打开所在文件夹/打开文件）——先定去哪，再定之后干嘛。
3. **PDF 自定义 CSS** pdfCss（textarea，挂「仅 PDF」角标）——生成期才起作用的原始样式，沉底。

### 07 应用
1. **主题** theme（seg：跟随系统/浅色/深色）。2. **界面语言** language（seg：中文/EN/日）。

## 3. 一致性规则（同类信息同构）

1. **模式 + 条件字段**（本 IA 的核心新模式）：主控 seg（含「无/关闭」档）置组/块首；条件字段收入统一的凹陷容器（`--inset` 底 + 左侧缩进轨），模式不满足时整块移除而非灰禁。首个实例 = headerMode；水印（F5）、目录增强（F7）复用同一容器组件。抽屉里**只保留这一种折叠形态**，纯信息折叠容器退役。
2. **枚举档位统一**：紧凑/标准/舒展三档永远以 seg 呈现、顺序固定、默认居中选中；命名格式「××档位」。适用：标题字号档位、标题间距档位。
3. **开关 + 说明格式**：13px 主标签 + 11.5px 灰色说明，说明写具体效果不写营销话；布尔开关永不用于枚举（align 即修正案例）。
4. **路径类同构**：outputDir / headerLogoPath / F9 导入共用 path-chip（mono、截断、ltr）+ 动作按钮模式。
5. **生效范围角标**：格式或场景受限项挂 mono 角标（复用最近列表的 .tag）：pdfCss「仅 PDF」、F8「仅合并」。
6. **预设作用域声明**：01 组的说明行是唯一的作用域文档点；04 组徽标与之呼应，双向互证。
7. **跨组副作用用 toast**：切换预设时以 toast 列出被覆盖的组（如「已应用 学术论文：覆盖 页面 · 文字 · 编号与目录」），2.4s 自动消失；toast 只陈述事实，不致歉不营销。

## 6. 决策记录（2026-08-25 已拍板）

1. headingScale 与 headingSpacing **保持两项独立**。
2. footerEnabled 作用域**仅自定义模式**；文案定名「自定义页脚」并注明生效条件，默认模式固定页码不受控。
3. 预设切换反馈采用 **toast 列出被覆盖的组**（控件模式已补入 ui-guidelines §2）。
4. F8 合并总目录落 **05 编号与目录族**（「仅合并」角标）。
5. 07 应用**保持独立成组**。

追加界面决策：

6. 历史记录改为**常驻可折叠区**（主舞台与消息区之间）：空态默认展开、有文件默认收起、无记录整块不渲染。
7. 默认窗高下历史不可见问题**授权直接修复**：压缩空态投放区垂直预算 + 历史列表内部滚动（约 3 行），最小窗高 620 内全要素免滚动可见；细节见 ui-guidelines §5。
